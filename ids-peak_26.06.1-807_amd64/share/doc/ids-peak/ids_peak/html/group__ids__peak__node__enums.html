◆ NodeCacheUsePolicy

enum class peak::core::nodes::NodeCacheUsePolicy
strong

Defines how node value access should interact with the internal cache.

See Node Caching and Polling Concepts.

This policy is used by read accessors such as FloatNode::Value, IntegerNode::Value, StringNode::Value, EnumerationNode::CurrentEntry, and RegisterNode::Read. It does not change whether a node is generally cacheable; it only controls how one specific read operation is executed.

Enumerator
UseCache 

Use cache according to cache and invalidation rules.

IgnoreCache 

Ignore cache for this read and request fresh data from the device.
