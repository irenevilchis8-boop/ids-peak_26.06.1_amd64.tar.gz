Detailed Description

RAII object that holds the NodeMap lock.

Instances of this class are returned by NodeMap::Lock() and keep the associated NodeMap locked for their lifetime. The lock is released automatically when the object is destroyed.

The lock is recursive: if the current thread already holds the lock, additional calls to NodeMap::Lock succeed without blocking. The lock is released only after all ScopedNodeMapLock instances acquired by the thread have been destroyed.

This class cannot be instantiated directly.
