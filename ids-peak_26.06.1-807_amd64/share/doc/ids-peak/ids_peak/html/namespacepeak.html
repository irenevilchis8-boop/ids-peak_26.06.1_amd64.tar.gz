Detailed Description

The "peak" namespace directly contains convenience functionality like the DeviceManager as well as the global Library::Initialize() / Library::Close() functions, which must be called before/after usage of the library.

template<>
peak::ipl::Image peak::BufferPartTo ( const std::shared_ptr< peak::core::BufferPart > & part)
inline

Converts a core::BufferPart into a peak::ipl::Image.

This creates a peak::ipl::Image as a shallow copy of the buffer (i.e. using the same memory).

Parameters
[in]partThe buffer part to convert
Returns
The buffer part converted to an Image.
Remarks
Remember that the buffer part's memory is only under your control until you re-queue the buffer.
Since
1.8
Note
