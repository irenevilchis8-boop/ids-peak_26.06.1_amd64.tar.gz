Detailed Description

The FileAdapter is a utility class designed for accessing files stored in a RemoteDevice's persistent memory.

It provides convenient functions to Read, Write, and Delete files.

const std::string fileName = "UserData1";
const auto nodeMap = remoteDevice->NodeMaps().at(0);
peak::core::file::FileAdapter adapter(nodeMap, fileName);
// Write
std::vector<uint8_t> data{ dataSize };
adapter.Write(data);
// Read
const auto fileSize = adapter.Size();
data = adapter.Read(fileSize);
Note
The FileAdapter relies on certain nodes within the RemoteDevice. If these nodes are not present, the functions may not work properly. Check your device's manual to confirm the availability of these nodes.
  • FileSelector
  • FileOperationSelector
  • FileOperationExecute
  • FileSize
  • FileAccessBuffer
  • FileAccessLength
  • FileAccessOffset
  • ...

The FileAdapter class encapsulates the functions of the GenApi::FileProtocolAdapter.

Constructs a FileAdapter for a specific file name in the RemoteDevice's NodeMap.

const std::string fileName = "UserData1";
const auto nodeMap = remoteDevice->NodeMaps().at(0);
peak::core::file::FileAdapter adapter(nodeMap, fileName);

File names may vary depending on the device. To obtain a list of valid file names, you can either iterate through the AvailableEntries of the 'FileSelector' EnumerationNode or use the static FileAdapter::AvailableFileNames function. Some files may be read-only.

Common file names include:

  • UserData1
  • UserData2
  • CriticalEventLog

Returns the contents of the file that the adapter references.

To read the entire file, use FileAdapter::Size as the size argument.

const auto fileSize = adapter.Size();
auto data = adapter.Read(fileSize);

Alternatively, you can specify an offset and a smaller size to read only a part of the file content.
