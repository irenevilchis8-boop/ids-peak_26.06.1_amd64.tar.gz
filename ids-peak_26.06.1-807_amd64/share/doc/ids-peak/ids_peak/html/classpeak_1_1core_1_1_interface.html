Detailed Description

Represents a GenTL Interface module.

This class allows to query information about a GenTL Interface module and to enumerate its DeviceDescriptors, which allow you to open the corresponding Device.

Delivers information based on the given GenTL info command.

Parameters
[in]infoCommandThe GenTL info command.

This function can be used to query information going beyond the predefined info functions, based on the GenTL info commands of the corresponding module.

Example (error handling is omitted):

#include <peak/thirdparty/GenTL.h>
auto info = object->Info(GenTL::XX_INFO_XX);
// Cast depending on the delivered data type
if (info.dataType == GenTL::INFO_DATATYPE_UINT64)
{
uint64_t uint64Var = *reinterpret_cast<const uint64_t*>(info.data.data());
// Do something with the information
}
else if (infoDataTypeVar == GenTL::INFO_DATATYPE_INT64)

...
}

◆ UpdateDevices()

void peak::core::Interface::UpdateDevices ( Timeout timeout_ms)
inline

Searches for devices.

This function triggers an update of the internal device list. The callbacks registered on the interface will be triggered if an device is found or lost.

Parameters
[in]timeout_msThe time to wait for new devices in milliseconds. In any case the GenTL Producer must make sure that this operation is completed in a reasonable amount of time depending on the underlying technology.
