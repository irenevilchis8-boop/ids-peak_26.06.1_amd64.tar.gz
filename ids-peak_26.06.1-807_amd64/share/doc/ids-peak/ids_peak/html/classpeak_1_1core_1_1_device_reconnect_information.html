◆ GetErrorFlags()

PEAK_DEVICE_RECONNECT_ERROR_FLAGS peak::core::DeviceReconnectInformation::GetErrorFlags ( ) const
inline

Returns error flags indicating the failed reconnect operation and the corresponding error.

If an error occurs during a reconnect this flag field indicates the failed reconnect operation as well as a more detailed error flag. Based on the error the users application can complete the missing reconnect operations, e.g. reallocating the buffers if the PEAK_DEVICE_RECONNECT_OPERATION_REMOTE_DEVICE_ACQUISITION_RESTART_PAYLOAD_SIZE_LARGER_THAN_BUFFERS flag is set.
