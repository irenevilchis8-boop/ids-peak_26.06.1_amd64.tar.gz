Detailed Description

The global DeviceManager (singleton) searches all installed producer libraries (*.cti) and enumerates the modules contained in them.

Retrieve the global DeviceManager with DeviceManager::Instance().

When Update() is called, it searches for all producer libraries contained in the directories found in the official GenICam GenTL environment variable GENICAM_GENTL{32/64}_PATH. It then openes all found ProducerLibraries, their Systems, their Interfaces, and lists all available DeviceDescriptors.

auto& deviceManager = peak::DeviceManager::Instance();
deviceManager.Update();
deviceDescriptors = deviceManager.Devices();

static DeviceManager & Instance()

Note
The found producer libraries depend on the architecture your application is compiled for. This means you are getting 32-bit producer libraries if your application is compiled for a 32-bit system and 64-bit producer libraries if your application is compiled for a 64-bit system.

The DeviceManager is a singleton. Therefore, after it was used, it stays active until program termination. That means the opened ProducerLibraries, Systems, and Interfaces stay open. To close them before and start from scratch during runtime, call Reset().

◆ Reset()

void peak::DeviceManager::Reset ( ResetPolicy resetPolicy = ResetPolicy::ErrorOnOpenDevices)
inline

Resets the DeviceManager.

All Interfaces and Systems are closed, additional ProducerLibraries (added via AddProducerLibrary()) are cleared. Any registered callbacks stay active and the DeviceLostCallback and InterfaceLostCallback are called for all devices / interfaces.

Note
Can't reset the DeviceManager while there are open Devices. Close all devices before calling this method. Otherwise, a core::InternalErrorException is thrown.
Parameters
[in]resetPolicyWith the default ResetPolicy::ErrorOnOpenDevices, an exception is thrown if there are any open devices managed by the DeviceManager. With ResetPolicy::IgnoreOpenDevices, no such exception is thrown.
Since
1.0
Exceptions
core::InternalErrorExceptionIf there are open devices (with ResetPolicy::ErrorOnOpenDevices).
