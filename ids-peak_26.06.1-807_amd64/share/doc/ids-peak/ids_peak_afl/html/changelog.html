Changelog

List of changes in each version

Warning
This changelog is no longer maintained. A comprehensive changelog that includes all components of the software is available for download on our website, located next to the setup file.

v1.8.1

Bug Fixes

  • Added deprecation attributes to deprecated functions and enumeration entries.

    This can lead to deprecation warnings at compile time.

    • RegisterDataProcessingCallback: use RegisterProcessingCallback instead.
    • UnRegisterDataProcessingCallback: use UnRegisterProcessingCallback instead.
    • PEAK_AFL_CONTROLLER_BRIGHTNESS_COMPONENT_GAIN: use specific gain types instead: PEAK_AFL_CONTROLLER_BRIGHTNESS_COMPONENT_ANALOG_GAIN, PEAK_AFL_CONTROLLER_BRIGHTNESS_COMPONENT_DIGITAL_GAIN, PEAK_AFL_CONTROLLER_BRIGHTNESS_COMPONENT_COMBINED_GAIN or PEAK_AFL_CONTROLLER_BRIGHTNESS_COMPONENT_HOST_GAIN.
    • PEAK_AFL_CONTROLLER_CALLBACK_PROCESSING_DATA: use PEAK_AFL_CONTROLLER_CALLBACK_PROCESSING instead.
    • PEAK_AFL_CALLBACK_PROCESSING_DATA_FUNC: use PEAK_AFL_CALLBACK_PROCESSING_FUNC instead.

v1.8.0

Features

  • Added BasicAutoFeatures and AdvancedAutoFeatures pipeline modules

    These modules integrate with the new image pipeline and provide automatic control of brightness, focus, and white balance.

    • BasicAutoFeatures offers a simplified setup with configuration options tailored to common use cases.
    • AdvancedAutoFeatures extends this functionality enabling fine-grained control for more demanding scenarios.
  • Add support to set a color correction matrix
  • Add support to natively process RGB8/RGBa8 pixel formats
  • Add a function to check if a specific controller is supported

Bug Fixes

  • Fix erroneously blocking the use of Sobel as the sharpness calculation algorithm for auto focus

v1.7.0

Features

  • Add new data processing callbacks
  • Add a new process callback for all controllers, so the user is informed when the image has been processed.

Bug Fixes

  • Fix a bug which resulted in an incorrect ROI.

v1.6.1

  • Fix a bug where SetGainIPL could not be used from C#
  • Fix a bug where the focus controller returned an incorrect status code when not supported.
  • Fix a bug in the automatic brightness controller when part of a combined brightness controller where the next or previous controller was not started although the limit value was reached

v1.6.0

  • Add average calculation algorithm for the auto controller, see Get, Set and IsSupported and the equivalent C++ methods (SetBrightnessAlgorithm, GetBrightnessAlgorithm and IsBrightnessAlgorithmSupported
  • Add auto gain control units for analog, digital, combined and host gain features
  • Add support for BGRa8 color format for the whitebalance controller

v1.5.0

  • Python Bindings:
    • The bindings now embed their direct runtime dependencies, excluding the transport layers and drivers
    • Indirect dependencies are resolved using package requirements
  • Fix dynamic loader

v1.4.0

  • Change the python bindings to use the Python Limited API
    • The minimum required python version is 3.7. They can be installed on any later 3.x version
  • Add an exposure limit to the auto controller, see Get, Set and IsSupported and the equivalent C++ methods (GetExposureLimit and SetExposureLimit)

v1.3.1

  • Add digital signature to dotnet assemblies
