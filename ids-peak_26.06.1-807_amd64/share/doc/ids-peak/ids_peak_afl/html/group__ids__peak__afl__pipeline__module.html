Detailed Description

High-level interfaces for automatic camera control through integrated auto feature management.

Pipeline Module

The Pipeline Module provides high-level interfaces for automatic camera control through integrated auto feature management. It offers two main classes that combine multiple controllers into unified, easy-to-use modules.

The following pipeline module classes are available:

  • BasicAutoFeatures - Simplified interface with basic controllers
  • AdvancedAutoFeatures - Sophisticated interface with advanced controllers

Both classes provide automatic control for:

  • Auto brightness - Exposure and gain control
  • Auto focus - Lens focus positioning
  • Auto white balance - Color correction

Key Features

Unified Interface

A single point of access for all auto features, eliminating the need to manage individual controllers separately.

Bulk Configuration

Convenient methods in the BasicAutoFeatures for configuring multiple controllers simultaneously:

  • SetAllModes() - Configure operation mode for all controllers
  • SetAllSkipFrames() - Set frame skipping strategy across all controllers

Device Integration

Direct integration with camera devices through the [device interface], automatically detecting and configuring available auto features based on device capabilities.

Serialization Support

Complete configuration persistence allowing you to save and restore auto feature settings.

BasicAutoFeatures vs AdvancedAutoFeatures

BasicAutoFeatures

  • Target audience: Standard auto features
  • Interface: Simplified methods with direct function access
  • Configuration: Policy-based brightness control
  • Complexity: Lower learning curve

AdvancedAutoFeatures

  • Target audience: Advanced auto features e.g. brightness component access
  • Interface: Granular control over individual feature components
  • Configuration: Component-specific parameter control
  • Complexity: Full algorithmic control

Basic Setup Example

// Create basic auto features module
auto autoFeatures = std::make_shared<peak::pipeline::modules::BasicAutoFeatures>(device);
// Configure all controllers with bulk methods
autoFeatures->SetAllModes(peak::pipeline::modules::autofeature::ControllerMode::Continuous);
autoFeatures->SetAllSkipFrames(2); // Process every 3rd frame
// Enable the overall system
autoFeatures->SetEnabled(true);

Individual Controller Access

Brightness Control

if (autoFeatures->HasAutoBrightness())
{
auto& brightness = autoFeatures->AutoBrightness();
brightness.SetAutoTarget(128);
brightness.SetPolicy(peak::pipeline::modules::autofeature::AutoBrightnessPolicy::ExposureAndGain);
brightness.SetMode(peak::pipeline::modules::autofeature::ControllerMode::Continuous);
}

Focus Control

if (autoFeatures->HasAutoFocus())
{
auto& focus = autoFeatures->AutoFocus();
focus.SetSearchAlgorithm(peak::pipeline::modules::autofeature::FocusSearchAlgorithm::GoldenRatio);
focus.SetSharpnessAlgorithm(peak::pipeline::modules::autofeature::FocusSharpnessAlgorithm::Tenengrad);
focus.SetMode(peak::pipeline::modules::autofeature::ControllerMode::Once);
}

White Balance Control

if (autoFeatures->HasAutoWhiteBalance())
{
auto& whiteBalance = autoFeatures->AutoWhiteBalance();
whiteBalance.SetRoi({ { 100, 100 }, { 300, 200 } });
whiteBalance.SetMode(peak::pipeline::modules::autofeature::ControllerMode::Continuous);
}

Controller Modes

The pipeline modules support different operation modes for each controller:

  • ControllerMode::Off - Controller is disabled
  • ControllerMode::Continuous - Automatic processing on every frame
  • ControllerMode::Once - Single operation triggered once

Frame Skipping

Reduce computational load and controller stabilization by processing only every Nth frame:

// Set for all controllers
autoFeatures->SetAllSkipFrames(4); // Process every 5th frame
// Or set individually
autoFeatures->AutoBrightness().SetSkipFrames(2);
autoFeatures->AutoFocus().SetSkipFrames(10);

Conditional Processing

Always check controller availability before configuration:

if (autoFeatures->HasAutoBrightness())
{
// Safe to configure brightness controller
}

Error Handling

Parameter Validation

// Validate parameters against supported ranges
auto targetRange = brightness.GetAutoTargetRange();
if (desiredTarget >= targetRange.GetMinimum() && desiredTarget <= targetRange.GetMaximum())
{
brightness.SetAutoTarget(desiredTarget);
}

Exception Handling

try
{
auto result = autoFeatures->Process(imageHandle);
}
catch (const peak::common::NotSupportedException& /*e*/)
{
// Handle unsupported feature
}
catch (const peak::common::InvalidParameterException& /*e*/)
{
// Handle invalid parameter
}

Configuration Persistence

Saving Configuration

peak::icv::Archive archive;
autoFeatures->Serialize(archive);
// Save archive to file

Loading Configuration

// Load archive from file
autoFeatures->Deserialize(archive);
Note
The pipeline module automatically handles device capability detection and only enables supported controllers.
For maximum performance and controller stabilization, use appropriate skip frames settings and controller modes based on your application requirements.
