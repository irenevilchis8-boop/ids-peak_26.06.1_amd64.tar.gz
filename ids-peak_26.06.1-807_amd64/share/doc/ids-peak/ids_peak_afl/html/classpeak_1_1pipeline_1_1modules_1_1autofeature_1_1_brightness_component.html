Detailed Description

Brightness component feature implementation for auto controllers.

The BrightnessComponent class provides a comprehensive interface for managing individual brightness components in automatic exposure systems. Each component represents a specific aspect of brightness control (exposure, gain types) with its own mode, limits, and callback mechanisms.

Key features:

  • Component-specific control: Manage exposure, analog gain, digital gain, etc.
  • Mode management: Set automatic, manual, or other control modes
  • Limit enforcement: Define valid ranges for component values
  • Callback support: Receive notifications when component operations complete
  • Serialization: Persist component configuration

This class is designed to work with the auto brightness system's component architecture, allowing fine-grained control over individual brightness parameters.

Note
This class is non-copyable and non-movable to ensure proper resource management and callback registration.
