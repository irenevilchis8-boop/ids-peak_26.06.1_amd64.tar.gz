Detailed Description

Specialized automatic control implementations for camera features within the pipeline module framework.

Pipeline Controllers

The Pipeline Controllers provide specialized automatic control implementations for camera features within the pipeline module framework. These controllers offer both basic and advanced interfaces for brightness, focus, and white balance control.

The following pipeline controller classes are available:

Basic Controllers

The features within the advanced controller are accessed via the direct function interface.

  • BasicAutoBrightness - Simplified brightness control with policy-based adjustment
  • BasicAutoFocus - Standard focus control with direct function access
  • BasicAutoWhiteBalance - Fundamental white balance correction

Advanced Controllers

The features within the advanced controller are accessed via the feature interface.

  • AdvancedAutoBrightness - Sophisticated brightness control with component-specific settings
  • AdvancedAutoFocus - Advanced focus control with feature interface
  • AdvancedAutoWhiteBalance - Advanced white balance with custom algorithms

Key Features

Basic Controllers

  • Simplified Interface: Direct setter methods for common parameters
  • Policy-Based Control: Unified control strategies (e.g., ExposureAndGain, ExposureOnly, GainOnly)
  • Essential Parameters: Core functionality with reduced complexity
  • Streamlined Configuration: Fewer options, easier setup

Advanced Controllers

  • Granular Control: Component-specific parameter adjustment
  • Extended Features: Additional configuration options and fine-tuning (brightness components)
  • Professional Applications: Optimized for demanding imaging requirements

Basic Controllers Usage

BasicAutoBrightness

The BasicAutoBrightness controller provides essential brightness control through exposure and gain adjustment with simplified configuration.

#include <peak_afl/pipeline/modules/controllers/peak_afl_basic_auto_brightness.hpp>
auto& brightness = basicAutoFeature.AutoBrightness();
// Configure brightness policy
brightness.SetPolicy(peak::pipeline::modules::autofeature::AutoBrightnessPolicy::ExposureAndGain);
// Set target brightness and tolerance
brightness.SetAutoTarget(128);
brightness.SetAutoTolerance(15);
// Configure exposure and gain limits
brightness.SetExposureLimit({ 0.001, 0.1 }); // 1ms to 100ms
brightness.SetGainLimit({ 1.0, 16.0 }); // 1x to 16x gain
// Set analysis algorithm
brightness.SetAnalysisAlgorithm(peak::pipeline::modules::autofeature::BrightnessAnalysisAlgorithm::Mean);
// Enable continuous mode
brightness.SetMode(peak::pipeline::modules::autofeature::ControllerMode::Continuous);

BasicAutoFocus

The BasicAutoFocus controller offers standard focus control with essential search and sharpness algorithms.

#include <peak_afl/pipeline/modules/controllers/peak_afl_basic_auto_focus.hpp>
auto& focus = basicAutoFeature.AutoFocus();
// Configure search and sharpness algorithms
focus.SetSearchAlgorithm(peak::pipeline::modules::autofeature::FocusSearchAlgorithm::GoldenRatio);
focus.SetSharpnessAlgorithm(peak::pipeline::modules::autofeature::FocusSharpnessAlgorithm::Tenengrad);
// Set focus limits and hysteresis
focus.SetFocusLimit({ 100, 900 });
focus.SetHysteresis(8);
// Configure weighted ROIs for focus evaluation
std::vector<peak::pipeline::modules::autofeature::WeightedROI> rois = { { { { 200, 200 }, { 400, 300 } },
peak::pipeline::modules::autofeature::Weight::Strong } };
focus.SetWeightedROIs(rois);
// Set skip frames for performance
focus.SetSkipFrames(2);
// Enable once mode for single focus operation
focus.SetMode(peak::pipeline::modules::autofeature::ControllerMode::Once);

BasicAutoWhiteBalance

The BasicAutoWhiteBalance controller provides fundamental color correction capabilities.

#include <peak_afl/pipeline/modules/controllers/peak_afl_basic_auto_white_balance.hpp>
// Create white balance controller with callback
auto& whiteBalance = basicAutoFeature.AutoWhiteBalance();
// Set region of interest for analysis
whiteBalance.SetRoi({ { 150, 150 }, { 300, 200 } });
// Configure frame skipping
whiteBalance.SetSkipFrames(3);
// Enable continuous mode
whiteBalance.SetMode(peak::pipeline::modules::autofeature::ControllerMode::Continuous);

Advanced Controllers Usage

AdvancedAutoBrightness

The AdvancedAutoBrightness controller provides sophisticated brightness control with component-specific configuration.

#include <peak_afl/pipeline/modules/controllers/peak_afl_advanced_auto_brightness.hpp>
// Create advanced brightness controller
auto& brightness = advancedAutoFeature.AutoBrightness();
// Configure advanced analysis algorithms
brightness.AnalysisAlgorithm().Set(
peak::pipeline::modules::autofeature::BrightnessAnalysisAlgorithm::Median);
brightness.AutoPercentile().Set(85.0);
// Set target and tolerance with precision
brightness.AutoTarget().Set(135);
brightness.AutoTolerance().Set(6);
// Component-specific configuration (advanced feature)
// Configure individual exposure, analog gain, digital gain components
// with separate limits and modes for each component
// Enable continuous mode
brightness.SetMode(peak::pipeline::modules::autofeature::ControllerMode::Continuous);

AdvancedAutoFocus

The AdvancedAutoFocus controller offers professional focus control with advanced algorithms and features.

#include <peak_afl/pipeline/modules/controllers/peak_afl_advanced_auto_focus.hpp>
// Create advanced focus controller
auto& focus = advancedAutoFeature.AutoFocus();
// Configure advanced search algorithms
focus.SearchAlgorithm().Set(peak::pipeline::modules::autofeature::FocusSearchAlgorithm::GlobalSearch);
focus.SharpnessAlgorithm().Set(
peak::pipeline::modules::autofeature::FocusSharpnessAlgorithm::HistogramVariance);
// Advanced ROI configuration with multiple weighted regions
std::vector<peak::pipeline::modules::autofeature::WeightedROI> advancedRois = {
{ { { 100, 100 }, { 150, 150 } },
peak::pipeline::modules::autofeature::Weight::Strong }, // Primary subject
{ { { 300, 150 }, { 100, 100 } },
peak::pipeline::modules::autofeature::Weight::Medium }, // Secondary area
{ { { 200, 300 }, { 120, 80 } },
peak::pipeline::modules::autofeature::Weight::Weak } // Background element
};
focus.WeightedROIs().Set(advancedRois);
// Fine-tuned parameters
focus.FocusLimit().Set({ 50, 950 });
focus.Hysteresis().Set(3);
focus.SkipFrames().Set(1);
// Enable once mode
focus.SetMode(peak::pipeline::modules::autofeature::ControllerMode::Once);

AdvancedAutoWhiteBalance

The AdvancedAutoWhiteBalance controller provides sophisticated color correction with custom algorithms.

#include <peak_afl/pipeline/modules/controllers/peak_afl_advanced_auto_white_balance.hpp>
// Create advanced white balance controller
auto& whiteBalance = advancedAutoFeature.AutoWhiteBalance();
// Precise ROI configuration
whiteBalance.Roi().Set({ { 160, 120 }, { 320, 240 } });
// Advanced algorithm configuration
// Custom white balance algorithms and parameters available
// Performance optimization
whiteBalance.SkipFrames().Set(2);
// Enable continuous mode
whiteBalance.SetMode(peak::pipeline::modules::autofeature::ControllerMode::Continuous);

Common Patterns

Mode Configuration

// All controllers support the same modes
brightness.SetMode(peak::pipeline::modules::autofeature::ControllerMode::Off); // Disabled
brightness.SetMode(peak::pipeline::modules::autofeature::ControllerMode::Continuous); // Every frame
brightness.SetMode(peak::pipeline::modules::autofeature::ControllerMode::Once); // Single operation
whiteBalance.SetMode(peak::pipeline::modules::autofeature::ControllerMode::Off); // Disabled
whiteBalance.SetMode(peak::pipeline::modules::autofeature::ControllerMode::Continuous); // Every frame
whiteBalance.SetMode(peak::pipeline::modules::autofeature::ControllerMode::Once); // Single operation

Callback Registration

// Register completion callbacks
auto handle = brightness.RegisterFinishedCallback([]() { std::cout << "Processing complete" << std::endl; });
// Unregister when no longer needed
brightness.UnregisterFinishedCallback(handle);
Note
All pipeline controllers inherit from the base IController interface and provide consistent behavior patterns.
Basic controllers are recommended for most applications, while advanced controllers should be used when specific algorithmic control or component-level configuration is required.
Controllers are designed to be used within the Pipeline Module framework but can also be used independently.
