Detailed Description

Host-side gain range limits for brightness control.

With this feature it is possible to define precisely the allowed range of the exposure time or gains for automatic adjustments, when auto brightness is enabled.

PEAK_AFL_API_STATUS peak_afl_AutoController_GainHostLimit_Set ( peak_afl_controller_handle controller,
peak_afl_double_limit limit )

Set autofeature host gain limit for a controller.

Configures the host gain limits for gain processing performed on the host system (CPU/software-based gain). Host gain provides maximum flexibility and precision but may have performance implications compared to hardware-based gain stages.

The valid values are dependent on the used gain node and can be between minimum and maximum. Default is the complete range.

If any value of the limit is out of range, the value is clamped to be valid. In this case, the function returns with PEAK_AFL_STATUS_VALUE_ADJUSTED. It is recommended to check the current values by calling peak_afl_AutoController_GainHostLimit_Get after this call.

Parameters
[in]controllercontroller handle
[in]limitLimits the controller to adjust the host gain to the supplied range between min and max of limit.
Returns
PEAK_AFL_STATUS_SUCCESS Operation was successful; no error occurred.
PEAK_AFL_STATUS_NOT_INITIALIZED The library is not initialized.
PEAK_AFL_STATUS_INVALID_PARAMETER The argument is invalid.

PEAK_AFL_STATUS_NOT_SUPPORTED The function is not supported.
PEAK_AFL_STATUS_ERROR An unexpected internal error occurred.
