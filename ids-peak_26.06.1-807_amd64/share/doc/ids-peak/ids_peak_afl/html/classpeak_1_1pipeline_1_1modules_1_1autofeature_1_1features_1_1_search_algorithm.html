Detailed Description

Search algorithm feature implementation for auto focus controllers.

The SearchAlgorithm class provides a feature interface for managing the focus search algorithm used by auto focus controllers. This feature controls which algorithm the automatic focus system uses to find the optimal focus position.

Different algorithms provide different trade-offs:

  • Auto: Lets the controller automatically select the default algorithm
  • GoldenRatio: Efficient binary search, good for smooth focus curves
  • HillClimbing: Fast local search, good when starting near optimal focus
  • GlobalSearch: Comprehensive search, more robust but slower
  • FullScan: Scans entire range, most accurate but slowest

This class inherits from IListFeature<FocusSearchAlgorithm> and provides both current algorithm management and a list of supported algorithms.

Note
Algorithm availability may vary based on the underlying controller implementation and lens characteristics.
