Detailed Description

Advanced automatic white balance controller with comprehensive feature set.

The AdvancedAutoWhiteBalance class provides a sophisticated and highly configurable interface for automatic white balance control. This controller offers the complete white balance feature set with granular control over all color correction mechanisms and algorithmic options.

Advanced Features:

  • Precision color analysis: Algorithms for accurate color temperature detection
  • Complex ROI management: Multiple region analysis for challenging lighting scenarios
  • Processing callbacks: Real-time feedback during white balance operations
  • Full serialization: Complete configuration state management
  • Controller modes: Continuous, once, and manual white balance control
Note
This controller requires a valid manager instance for camera communication
Advanced features may require specific hardware color processing capabilities
Processing callback provides real-time operation feedback
For simplified usage, consider BasicAutoWhiteBalance instead
