Detailed Description

Configurable parameters and algorithms for automatic camera control within the pipeline framework.

Pipeline Features

The Pipeline Features provide configurable parameters and algorithms for automatic camera control within the pipeline framework. These features are building blocks used by pipeline controllers to implement sophisticated automatic control functionality.

The pipeline features are organized into several categories:

Core Feature Interfaces

  • IFeature - Base interface for all features
  • IListFeature - Interface for features with enumerated values
  • IRangeFeature - Interface for features with numeric ranges

Brightness Control Features

  • AutoTarget - Target brightness value configuration
  • AutoTolerance - Brightness tolerance settings
  • AutoPercentile - Percentile-based brightness analysis
  • BrightnessAlgorithm - Brightness analysis algorithms
  • BrightnessComponent - Individual brightness components
  • BrightnessLimit - Brightness range limits

Focus Control Features

  • FocusLimit - Focus position range limits
  • Hysteresis - Focus stability control
  • SearchAlgorithm - Focus search algorithms
  • SharpnessAlgorithm - Sharpness measurement algorithms
  • WeightedROIs - Multi-region focus evaluation

General Control Features

  • ROI - Region of interest configuration
  • SkipFrames - Frame processing optimization

Feature Architecture

Base Interfaces

IFeature

The base interface for all pipeline features providing common functionality:

  • Serialization: Save and restore feature configurations
  • Validation: Parameter range checking and validation
  • Type Safety: Strongly typed parameter access

IListFeature

Specialized interface for features with enumerated values:

  • Enumeration Support: Predefined value lists (e.g., algorithms)
  • List Access: Get available options for UI population
  • Validation: Automatic validation against supported values

IRangeFeature

Specialized interface for features with numeric ranges:

  • Range Validation: Automatic min/max boundary checking
  • Device Limits: Integration with device capability ranges
  • Type Safety: Templated for different numeric types

Brightness Features Usage

AutoTarget

Configures the desired brightness level for automatic adjustment:

#include <peak_afl/pipeline/modules/controllers/features/peak_afl_auto_target.hpp>
// Create auto target feature
auto targetFeature = std::make_shared<peak::pipeline::modules::autofeature::features::AutoTarget>(
controller);
// Set target brightness value
targetFeature->Set(128); // 0-255 range typically
// Get current target
uint32_t currentTarget = targetFeature->Get();
// Get valid range
auto range = targetFeature->GetRange();
std::cout << "Valid range: " << range.GetMinimum() << " - " << range.GetMaximum() << std::endl;

AutoTolerance

Defines acceptable deviation from target brightness:

#include <peak_afl/pipeline/modules/controllers/features/peak_afl_auto_tolerance.hpp>
// Create tolerance feature
auto toleranceFeature = std::make_shared<peak::pipeline::modules::autofeature::features::AutoTolerance>(
controller);
// Set tolerance value
toleranceFeature->Set(15); // Acceptable deviation
// Smaller tolerance = more stable brightness, larger = less frequent adjustments

BrightnessAlgorithm

Selects the algorithm for brightness analysis:

#include <peak_afl/pipeline/modules/controllers/features/peak_afl_brightness_algorithm.hpp>
// Create algorithm feature
auto algorithmFeature =
std::make_shared<peak::pipeline::modules::autofeature::features::BrightnessAlgorithm>(controller);
// Set analysis algorithm
algorithmFeature->Set(peak::pipeline::modules::autofeature::BrightnessAnalysisAlgorithm::Median);

Focus Features Usage

SearchAlgorithm

Configures the focus search strategy:

#include <peak_afl/pipeline/modules/controllers/features/peak_afl_search_algorithm.hpp>
// Create search algorithm feature
auto searchFeature = std::make_shared<peak::pipeline::modules::autofeature::features::SearchAlgorithm>(
controller);
// Set search algorithm
searchFeature->Set(peak::pipeline::modules::autofeature::FocusSearchAlgorithm::GoldenRatio);
// Available algorithms: Auto, GoldenRatio, HillClimbing, GlobalSearch, FullScan

SharpnessAlgorithm

Configures the sharpness measurement method:

#include <peak_afl/pipeline/modules/controllers/features/peak_afl_sharpness_algorithm.hpp>
// Create sharpness algorithm feature
auto sharpnessFeature =
std::make_shared<peak::pipeline::modules::autofeature::features::SharpnessAlgorithm>(controller);
// Set sharpness algorithm
sharpnessFeature->Set(peak::pipeline::modules::autofeature::FocusSharpnessAlgorithm::Tenengrad);
// Available algorithms: Auto, Tenengrad, Sobel, MeanScore, HistogramVariance

WeightedROIs

Configures multiple regions for focus evaluation:

#include <peak_afl/pipeline/modules/controllers/features/peak_afl_weighted_rois.hpp>
// Create weighted ROIs feature
auto roisFeature = std::make_shared<peak::pipeline::modules::autofeature::features::WeightedRois>(
controller);
// Configure multiple focus regions
std::vector<peak::pipeline::modules::autofeature::WeightedROI> rois = {
{ { { 200, 200 }, { 400, 300 } },
peak::pipeline::modules::autofeature::Weight::Strong }, // Primary focus area
{ { { 100, 100 }, { 150, 150 } },
peak::pipeline::modules::autofeature::Weight::Medium }, // Secondary area
{ { { 500, 400 }, { 100, 80 } },
peak::pipeline::modules::autofeature::Weight::Weak } // Background area
};
roisFeature->Set(rois);

FocusLimit

Sets the allowable focus position range:

#include <peak_afl/pipeline/modules/controllers/features/peak_afl_focus_limit.hpp>
// Create focus limit feature
auto limitFeature = std::make_shared<peak::pipeline::modules::autofeature::features::FocusLimit>(
controller);
// Set focus range limits
peak::common::Interval focusRange{ 100, 900 }; // Near to far limits
limitFeature->Set(focusRange);

Hysteresis

Prevents focus hunting and oscillation:

#include <peak_afl/pipeline/modules/controllers/features/peak_afl_hysteresis.hpp>
// Create hysteresis feature
auto hysteresisFeature = std::make_shared<peak::pipeline::modules::autofeature::features::Hysteresis>(
controller);
// Set hysteresis value
hysteresisFeature->Set(8); // Higher values = more stability, less responsiveness

General Features Usage

ROI (Region of Interest)

Defines the analysis area for white balance and other operations:

#include <peak_afl/pipeline/modules/controllers/features/peak_afl_roi.hpp>
// Create ROI feature
auto roiFeature = std::make_shared<peak::pipeline::modules::autofeature::features::Roi>(controller);
// Set region of interest
peak::common::Rectangle roi{ { 150, 150 }, { 300, 200 } };
roiFeature->Set(roi);

SkipFrames

Optimizes performance by processing every Nth frame:

#include <peak_afl/pipeline/modules/controllers/features/peak_afl_skip_frames.hpp>
// Create skip frames feature
auto skipFeature = std::make_shared<peak::pipeline::modules::autofeature::features::SkipFrames>(
controller);
// Set frame skipping (0 = process every frame, 2 = process every 3rd frame)
skipFeature->Set(2);
// Get valid range
auto range = skipFeature->GetRange();

Feature Serialization

All features support serialization for configuration persistence:

// Serialize feature configuration
peak::icv::Archive archive;
feature->Serialize(archive);
// Later, restore configuration
feature->Deserialize(archive);

Feature Validation

Features automatically validate parameters against device capabilities:

// Range validation example
auto targetFeature = std::make_shared<peak::pipeline::modules::autofeature::features::AutoTarget>(
controller);
auto range = targetFeature->GetRange();
uint32_t desiredValue = 200;
if (desiredValue >= range.GetMinimum() && desiredValue <= range.GetMaximum())
{
targetFeature->Set(desiredValue); // Safe to set
}
else
{
// Handle invalid value
std::cerr << "Value " << desiredValue << " outside valid range [" << range.GetMinimum() << ", "
<< range.GetMaximum() << "]" << std::endl;
}

Algorithm Features

Brightness Analysis Algorithms

Available brightness analysis methods:

  • Mean: Average-based analysis for general use
  • Median: Robust analysis for noisy conditions
  • Percentile: Customizable percentile-based analysis

Focus Search Algorithms

Available focus search strategies:

  • GoldenRatio: Efficient binary search
  • HillClimbing: Fast local optimization
  • GlobalSearch: Comprehensive search
  • FullScan: Complete range scan

Focus Sharpness Algorithms

Available sharpness measurement methods:

  • Tenengrad: Gradient-based measurement
  • Sobel: Edge detection based
  • MeanScore: Statistical approach
  • HistogramVariance: Variance-based measurement

Best Practices

Feature Configuration

// Always check ranges before setting values
auto range = feature->GetRange();
if (value >= range.min && value <= range.max) {
feature->Set(value);
}

Algorithm Selection

// Get available algorithms for UI population
auto algorithms = algorithmFeature->GetList();
// Present options to user or select programmatically

Error Handling

try
{
feature->Set(value);
}
catch (const peak::common::InvalidParameterException& /*e*/)
{
// Handle invalid parameter
}
Note
Pipeline features are designed to be used within pipeline controllers but can also be accessed directly for advanced configuration.
All features provide automatic parameter validation and serialization support for robust configuration management.
Feature availability depends on the underlying device capabilities and controller implementation.
