Detailed Description

White balance controller process data.

Extended process data structure for white balance controllers. Contains white balance-specific information including the calculated mean values for each color channel (RGB) and the current white balance component being processed.

Note
Cast from peak_afl_process_data when controller_type is WHITE_BALANCE
