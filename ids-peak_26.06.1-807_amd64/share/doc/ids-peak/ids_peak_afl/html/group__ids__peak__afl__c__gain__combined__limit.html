Detailed Description

Combined gain range limits for brightness control.

With this feature it is possible to define precisely the allowed range of the exposure time or gains for automatic adjustments, when auto brightness is enabled.

PEAK_AFL_API_STATUS peak_afl_AutoController_GainCombinedLimit_Set ( peak_afl_controller_handle controller,
peak_afl_double_limit limit )

Set autofeature combined gain limit for a controller.

Configures limits for the total combined gain (analog + digital). This allows you to constrain the overall amplification regardless of how it's distributed between analog and digital stages. Useful for maintaining overall image quality while allowing the controller to optimize the gain distribution.

The valid values are dependent on the used gain node and can be between minimum and maximum. Default is the complete range.

If any value of the limit is out of range, the value is clamped to be valid. In this case, the function returns with PEAK_AFL_STATUS_VALUE_ADJUSTED. It is recommended to check the current values by calling peak_afl_AutoController_GainCombinedLimit_Get after this call.
