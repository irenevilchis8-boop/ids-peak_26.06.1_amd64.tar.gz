Detailed Description

Acceptable deviation from target brightness settings.

The automatic control feature uses a tolerance function for stabilization. Automatic control is stopped when the actual value is within a range between (setpoint - tolerance value) and (setpoint + tolerance value). The control algorithm continues if the actual brightness value drops below (setpoint - tolerance value) or exceeds the desired target value (setpoint + tolerance value). If the tolerance value is increased, the control function will stop sooner. This can be useful in some situations.

Get the auto tolerance range for a controller.

Retrieves the valid range of tolerance values that can be configured for this controller. The range provides the minimum and maximum allowable tolerance values, as well as the increment step size. The available range depends on the controller type and implementation.

Call this function to determine valid tolerance values before calling peak_afl_AutoController_AutoTolerance_Set to avoid parameter errors.

PEAK_AFL_API_STATUS peak_afl_AutoController_AutoTolerance_Set ( peak_afl_controller_handle controller,
uint32_t tolerance )

Set the auto tolerance for a controller.

Sets the tolerance range around the auto target value. The tolerance defines the acceptable deviation from the target before the controller will make adjustments. For example, if the target is 128 and tolerance is 5, the controller will only adjust when the measured value falls outside the range of 123-133. This helps prevent oscillation and provides stable operation by creating a "dead zone" around the target value.

A smaller tolerance provides more precise control but may cause more frequent adjustments. A larger tolerance provides more stable operation but with less precision.
