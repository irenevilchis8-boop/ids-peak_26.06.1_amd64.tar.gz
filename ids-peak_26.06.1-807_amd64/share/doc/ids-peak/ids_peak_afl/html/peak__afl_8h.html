Detailed Description

C API interface for automatic camera feature control.

This header provides the complete C API for the auto feature library, enabling automatic control of camera parameters such as brightness, focus, and white balance.

Typedef Documentation

◆ peak_afl_controller_handle

typedef void* peak_afl_controller_handle

Opaque handle for auto feature controllers.

This handle represents an instance of an automatic feature controller (brightness, focus, or white balance). Controllers are created through manager instances and should be treated as opaque pointers.

Warning
