enum peak_afl_roi_preset

Predefined ROI preset configurations.

Defines commonly used ROI configurations that can be quickly applied to controllers without manually specifying coordinates. These presets automatically adapt to the current image size.

Center region preset.

PEAK_AFL_API_STATUS peak_afl_AutoController_ROI_Preset_IsSupported ( peak_afl_controller_handle controller,
peak_afl_BOOL8 * supported )

Check if ROI preset feature is supported for a controller.

Determines whether the specified controller supports predefined region of interest presets. ROI presets provide convenient, predefined rectangular regions that are commonly used for automatic feature processing, such as center regions, corner regions, or specific aspect ratio areas. This feature simplifies ROI configuration by offering standard options instead of requiring manual coordinate specification.

Parameters
[in]controllerController handle to check for ROI preset support
[out]supportedPointer to receive support status:
  • PEAK_AFL_TRUE: ROI preset feature is supported
  • PEAK_AFL_FALSE: ROI preset feature is not supported
Returns
PEAK_AFL_STATUS_SUCCESS Operation completed successfully
PEAK_AFL_STATUS_NOT_INITIALIZED The library is not initialized
PEAK_AFL_STATUS_INVALID_PARAMETER Invalid controller handle or NULL supported pointer
PEAK_AFL_STATUS_ERROR An unexpected internal error occurred
Note
Check this function before attempting to use ROI preset functionality
ROI preset support is independent of basic ROI support
Presets provide convenient alternatives to manual ROI coordinate specification
Available presets may vary between different controller implementations

PEAK_AFL_API_STATUS peak_afl_AutoController_ROI_Preset_Set ( peak_afl_controller_handle controller,
peak_afl_roi_preset roiPreset )

Set a predefined region of interest preset for a controller.

Configures the controller to use a predefined region of interest preset instead of manually specified coordinates. ROI presets provide convenient, standardized rectangular regions that are commonly used for automatic feature processing. This simplifies configuration by offering well-tested region definitions without requiring manual coordinate calculation.

Parameters
[in]controllerController handle for which to set the ROI preset
[in]roiPresetPredefined region of interest preset to apply. Available presets may include center regions, corner areas, or specific aspect ratios. See peak_afl_roi_preset for available options.
Returns
PEAK_AFL_STATUS_SUCCESS ROI preset configured successfully
PEAK_AFL_STATUS_NOT_INITIALIZED The library is not initialized
PEAK_AFL_STATUS_INVALID_PARAMETER Invalid controller handle or unsupported preset value
PEAK_AFL_STATUS_NOT_SUPPORTED ROI preset feature is not supported by this controller
PEAK_AFL_STATUS_ERROR An unexpected internal error occurred
Note
Check support with peak_afl_AutoController_ROI_Preset_IsSupported() before using
ROI presets override any manually set ROI coordinates
Preset regions are automatically scaled to match image dimensions
Changes take effect for subsequent image processing operations
Use peak_afl_AutoController_ROI_Set() for custom coordinate-based ROI
