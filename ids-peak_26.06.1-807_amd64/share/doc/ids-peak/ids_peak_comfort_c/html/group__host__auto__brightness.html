Detailed Description

Auto brightness control related functions and types.

This feature is applied in the host.
There is also a camera implementation. See Auto brightness control.

Auto brightness

Auto exposure

The control of the average brightness is preferably achieved by adjusting the exposure, i.e. you set the highest possible exposure time before gain is controlled. The auto exposure feature always uses the current exposure range within the active frame time. You can set separate control range limits for exposure.

Auto gain

The auto gain feature controls the supported camera gains and host gain. In digital imaging, a voltage proportional to the amount of incident light is output by the sensor. To increase image brightness and contrast, this signal can be amplified by an analog gain and offset before the digitizing process. The results of analog signal processing are usually better than the results of digital postprocessing. Digital gain is applied after the digitizing process. Analog, Digital, and Combined gain are applied by the camera while Host gain is applied by the host. You can set separate control range limits for every supported gain. There are two different possibilities to control the gains.

The Auto Gain Mode automatically selects the first available gain from a list of supported gains.

With the second mode, the supported gains can be enabled individually. Also it is possible to set limits for every individual gain.

The supported or activated gains will be chosen and controlled in the following order:

  1. Analog
  2. Digital
  3. Host

or

  1. Combined
  2. Host

It is only possible to run one mode. Enabling a mode automatically disables the previous one.

Enabling and automatically disabling the control function

For ongoing brightness adaptations the Continuous mode has to be used so that it responds to deviations from the target value. To disable the control functionality automatically once the target value has been reached (approximately) with the Once mode.

Configuring the control functions

Brightness calculation algorithm

Sets the algorithm which will be used for the auto brightness calculation. With mean the average value is found by adding all pixel values and dividing by the number of pixel. With median the middle number is found by ordering all pixel and picking the middle.

Target value

Sets the target value for auto brightness control. The percentage of pixels, that must be brighter than the target value, is defined in target Percentile. The value of target value does not relate to the current PixelFormat and can be specified in the range from 0 to 255.

Note
Increasing the target value results in brighter images, decreasing its value results in darker images. If the target value is set to a high value and percentile is set to its minimum, it behaves similar to a peak white algorithm. It is not recommended to push target value to its limits. Keep distance from the limits, i.e. use "250" instead of "255", or "5" instead of "0".

Target tolerance

The automatic control feature uses a tolerance function for stabilization. Automatic control is stopped when the actual value is within a range between (setpoint - tolerance value) and (setpoint + tolerance value). The control algorithm continues if the actual brightness value drops below (setpoint - tolerance value) or exceeds the desired target value (setpoint + tolerance value). If the tolerance value is increased, the control function will stop sooner. This can be useful in some situations.

Percentile

Defines the percentage of pixels that must be brighter than the target value. The percentile value is only used for the Median brightness calculation algorithm.

Skip frames

The Skip Frames setting selects how many frames should be skipped. This parameter strongly influences the control speed. Choosing small values can destabilize the automatic control.

Note
For higher frame rates, a larger value for the Skip frames parameter should be used. This reduces the number of automatic adjustments that must be done by the camera.

Restricting the control range

With this feature it is possible to precisely define the allowed range of the exposure time or gains for automatic adjustments, when auto brightness is enabled.

Examples

Note
For the automatic host control to work, the frames must be transferred to the IPL pipeline. To reduce and simplify the sample code, the examples do not check the return values.

Auto exposure with auto gain

// enable exposure and gain auto controller
peak_IPL_AutoBrightness_Exposure_Mode_Set(hCam, PEAK_AUTO_FEATURE_MODE_CONTINUOUS);
peak_IPL_AutoBrightness_Gain_Mode_Set(hCam, PEAK_AUTO_FEATURE_MODE_CONTINUOUS);
// run acquisition and auto brightness control loop
while(acquisition_running)
{
peak_Acquisition_WaitForFrame(hCam, 5000, &hFrame);
// forward frame to auto controller pipeline
peak_IPL_ProcessFrameInplace(hCam, hFrame);
// retrieve last calculated brightness average value
peak_IPL_AutoBrightness_AverageLast_Get(hCam, &lastAverage);
}

Auto exposure and individual auto gain control

// enable exposure and individual gain auto controller
peak_IPL_AutoBrightness_Exposure_Mode_Set(hCam, PEAK_AUTO_FEATURE_MODE_CONTINUOUS);
peak_IPL_AutoBrightness_GainAnalog_Mode_Set(hCam, PEAK_AUTO_FEATURE_MODE_CONTINUOUS);
peak_IPL_AutoBrightness_GainHost_Mode_Set(hCam, PEAK_AUTO_FEATURE_MODE_ONCE);
// allow full range for analog but limit the host auto gain
peak_double_limit limit = { .min = 4.0, .max = 6.0 };
peak_IPL_AutoBrightness_GainHostLimit_Set(hCam, limit);
// run acquisition and auto brightness control loop
// ...

Change auto brightness configuration settings

peak_IPL_AutoBrightness_Algorithm_Set(hCam, PEAK_AUTO_FEATURE_BRIGHTNESS_ALGORITHM_MEAN);
peak_IPL_AutoBrightness_Target_Set(hCam, 128);
peak_IPL_AutoBrightness_SkipFrames_Set(hCam, 4);
// run acquisition and auto brightness control loop
// ...

Enable message for auto exposure controller

peak_MessageQueue_EnableMessage(hQueue, hCam, PEAK_MESSAGE_TYPE_AUTO_BRIGHTNESS_EXPOSURE_ONCE_FINISHED);
// the message will only fire if mode is set to once and the target is reached
peak_IPL_AutoBrightness_Exposure_Mode_Set(hCam, PEAK_AUTO_FEATURE_MODE_ONCE);
// run acquisition and auto brightness control loop
// also wait for message to occur with peak_MessageQueue_WaitForMessage
// ...
