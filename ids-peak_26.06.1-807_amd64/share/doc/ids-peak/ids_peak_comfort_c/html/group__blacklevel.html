Detailed Description

Controls the analog black level.

This feature is only applied in the camera.

The black level is an offset that is applied to all pixel values. To set the offset manually, the black level auto must be disabled with peak_BlackLevel_Auto_Enable. Some cameras also support adding a manual offset to the automatic black level. For these, the peak_BlackLevel_Offset_GetAccessStatus status stays PEAK_ACCESS_READWRITE even after enabling black level auto with peak_BlackLevel_Auto_Enable.

Note
It is advised to set the desired black level value again after changing the pixel format, as some cameras will change the range automatically to the new pixel depth.
For some cameras, this also applies after black level auto has been enabled.

Example to use the black level feature:

peak_access_status accessStatus = peak_BlackLevel_Auto_GetAccessStatus(hCam);
if (PEAK_IS_READABLE(accessStatus))
{
peak_bool enabled = peak_BlackLevel_Auto_IsEnabled(hCam);
if (enabled)
{
// do something
}
}
if (PEAK_IS_WRITEABLE(accessStatus))
{
// Enable
peak_status status = peak_BlackLevel_Auto_Enable(hCam, PEAK_TRUE);
if (PEAK_ERROR(status))
{
// handle error
}
}
accessStatus = peak_BlackLevel_Offset_GetAccessStatus(hCam);
if (PEAK_IS_READABLE(accessStatus))
{
double blackLevel = 0.0;
peak_status status = peak_BlackLevel_Offset_Get(hCam, &blackLevel);
if (PEAK_ERROR(status))
{
// handle error
}
// do something with black level offset
}
if (PEAK_IS_WRITEABLE(accessStatus))
{
double blackLevelMin = 0.0, blackLevelMax = 0.0, blackLevelInc = 0.0;
peak_status status = peak_BlackLevel_Offset_GetRange(hCam, &blackLevelMin, &blackLevelMax, &blackLevelInc);
if (PEAK_ERROR(status))
{
// handle error
}
// Set max
status = peak_BlackLevel_Offset_Set(hCam, blackLevelMax);
if (PEAK_ERROR(status))
{
// handle error
}
}

◆ peak_BlackLevel_Auto_GetAccessStatus()

peak_access_status peak_BlackLevel_Auto_GetAccessStatus ( peak_camera_handle hCam)

Query black level auto access status.

Provides the current access status for the black level auto feature. Depending on the camera model the access status of black level auto may change.

This function implements the Access Status Query principle.

Parameters
[in]hCamThe camera handle.
Returns
PEAK_ACCESS_READWRITE The black level auto feature is readable and writeable.
PEAK_ACCESS_GFA_LOCK The black level auto feature is not accessible because the GFA write access is enabled.
PEAK_ACCESS_NONE The black level auto feature is not accessible.
PEAK_ACCESS_NOT_SUPPORTED The black level auto feature is not supported.
PEAK_ACCESS_INVALID The function failed. Call peak_Library_GetLastError to get the error code and description.

If the function indicates an error by returning PEAK_ACCESS_INVALID, these are the possible errors:

  • PEAK_STATUS_INVALID_HANDLE hCam is an invalid camera handle.
  • PEAK_STATUS_NOT_INITIALIZED The library is not initialized.
  • PEAK_STATUS_ERROR An unexpected internal error occurred.
Since
1.11
