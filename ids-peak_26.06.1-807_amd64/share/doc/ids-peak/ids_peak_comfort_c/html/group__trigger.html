Detailed Description

A trigger is a mechanism that synchronizes image capture with an external event or condition. This feature is crucial in applications where precise timing is needed to capture images at the right moment.

By using external signals — such as from sensors or actuators — the camera only captures images when necessary, conserving processing power and bandwidth. Triggers are key to optimizing performance, efficiency and precision in these systems.

Types of Triggers:

Hardware Trigger:
The camera captures an image upon receiving an electrical signal (e.g., a pulse) from an external device. Software Trigger:
A trigger initiated by software to command the camera to capture an image at a specified time.

Hardware Trigger

To obtain a list of available input channels, call peak_IOChannel_GetListForDirection with PEAK_IO_DIRECTION_INPUT as the direction parameter (see example).

The example code below demonstrates how to configure and activate a hardware trigger on line 0 for frame start.

peak_access_status access = peak_Trigger_GetAccessStatus(hCam);
if (access != PEAK_ACCESS_READWRITE)
{
// camera does not support trigger
}
peak_trigger_mode trigger_mode = { PEAK_TRIGGER_TARGET_FRAME_START, PEAK_IO_CHANNEL_LINE_0 };
access = peak_Trigger_Mode_GetAccessStatus(hCam, trigger_mode);
if (access != PEAK_ACCESS_READWRITE)
{
// this trigger mode is not available, check input channels
}
peak_status status = peak_Trigger_Mode_Set(hCam, trigger_mode);
if (PEAK_ERROR(status))
{
// handle error
}
status = peak_Trigger_Enable(hCam, PEAK_TRUE);
if (PEAK_ERROR(status))
{
// handle error
}
// start the image acquisition to acquire images with the hardware trigger

Software Trigger

Unlike a hardware trigger, which is activated by an external signal, a software trigger is controlled by the application.

The example code below illustrates how to configure and enable a software trigger for FrameStart, start the image acquisition and execute the software trigger three times to capture frames.

peak_trigger_mode trigger_mode = { PEAK_TRIGGER_TARGET_FRAME_START, PEAK_IO_CHANNEL_SOFTWARE };
peak_access_status access = peak_Trigger_Mode_GetAccessStatus(hCam, trigger_mode);
if (access != PEAK_ACCESS_READWRITE)
{
// the software trigger mode is not available
}
peak_status status = peak_Trigger_Mode_Set(hCam, trigger_mode);
if (PEAK_ERROR(status))
{
// handle error
}
status = peak_Trigger_Enable(hCam, PEAK_TRUE);
if (PEAK_ERROR(status))
{
// handle error
}
// start the image acquisition to acquire images with the hardware trigger
status = peak_Acquisition_Start(hCam, PEAK_INFINITE);
if (PEAK_ERROR(status))
{
// handle error
}
int received_frames = 0;
for (int i = 0; i < 3; i++)
{
// execute the software trigger to capture a frame
status = peak_Trigger_Execute(hCam);
if (PEAK_ERROR(status))
{
// handle error
}
peak_frame_handle frame = PEAK_INVALID_HANDLE;
status = peak_Acquisition_WaitForFrame(hCam, 5000, &frame);
if (PEAK_SUCCESS(status))
{
// do something with frame
received_frames++;
peak_Frame_Release(hCam, frame);
}
}
status = peak_Acquisition_Stop(hCam);
if (PEAK_ERROR(status))
{
// handle error
}

Configuration Options

Additional configuration options for the trigger include

the trigger edge, that initializes the image capture, the delay between the physical signal and the image capture, the trigger divider to ignore a specific number of trigger signals until the next image capture and the number of captured images on each trigger signal using a burst trigger.

Note
The availability of these options depends on the camera model and firmware version. It is highly recommended to verify the access status before executing the corresponding function.

◆ peak_Trigger_GetAccessStatus()

peak_access_status peak_Trigger_GetAccessStatus ( peak_camera_handle hCam)

Query the trigger feature access status.

Provides the current access status for the trigger feature.

This function implements the Access Status Query principle.

Parameters
[in]hCamThe camera handle.
Returns
PEAK_ACCESS_READWRITE The trigger feature is readable and writeable.
PEAK_ACCESS_READONLY The trigger feature is readable only.
PEAK_ACCESS_GFA_LOCK The trigger feature is not accessible because the GFA write access is enabled.
PEAK_ACCESS_NONE The trigger feature is not accessible. Check for a running acquisition.
PEAK_ACCESS_NOT_SUPPORTED The trigger feature is not supported.
PEAK_ACCESS_INVALID The function failed. Call peak_Library_GetLastError to get the error code and description.

If the function indicates an error by returning PEAK_ACCESS_INVALID, these are the possible errors:

  • PEAK_STATUS_INVALID_HANDLE hCam is an invalid camera handle.
  • PEAK_STATUS_NOT_INITIALIZED The library is not initialized.
  • PEAK_STATUS_ERROR An unexpected internal error occurred.

Set the trigger mode.

Changes the trigger mode.

The properties of the trigger will be reset to the following default values:

  • The trigger edge will be set to PEAK_TRIGGER_EDGE_RISING.
  • The trigger delay will be set to 0.
  • The trigger divider will be set to 1.
