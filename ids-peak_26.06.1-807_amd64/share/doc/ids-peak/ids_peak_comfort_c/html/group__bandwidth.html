Detailed Description

Bandwidth related functions and types.

Bandwidth control involves regulating the rate at which data is transferred from the camera to the host, ensuring that the data does not exceed the network's capacity, and optimizing performance to prevent issues like data congestion, frame loss, and latency. This is essential for maintaining precise image capture and smooth operation in industrial applications.

Note
For each sub feature the corresponding AccessStatus functions should be called first, as not all camera types support each sub feature.

Link Speed

The maximum data transfer rate negotiated between the camera and the network after connection. It helps determine if the camera is connected via SuperSpeed or Hi-Speed USB for USB cameras or the network speed for ethernet cameras.

The following example shows how to check the camera link speed and compare it with the nominal interface speed.

const peak_access_status access = peak_Bandwidth_LinkSpeed_GetAccessStatus(hCam);
if (!PEAK_IS_READABLE(access))
{
return;
}
int64_t linkSpeed = 0;
peak_status status = peak_Bandwidth_LinkSpeed_Get(hCam, &linkSpeed);
if (PEAK_ERROR(status))
{
return;
}
peak_camera_descriptor descriptor = { 0 };
status = peak_Camera_GetDescriptor(peak_Camera_ID_FromHandle(hCam), &descriptor);
if (PEAK_ERROR(status))
{
return;
}
if (descriptor.cameraType == PEAK_CAMERA_TYPE_UEYE_USB || descriptor.cameraType == PEAK_CAMERA_TYPE_UEYE_PLUS_U3V)
{
if (linkSpeed < PEAK_LINKSPEED_USB3_SUPER_SPEED)
{
// camera running with USB 2 HighSpeed or lower
}
else
{
// camera running with USB 3 SuperSpeed or higher
}
}
else if (descriptor.cameraType == PEAK_CAMERA_TYPE_UEYE_ETH || descriptor.cameraType == PEAK_CAMERA_TYPE_UEYE_PLUS_GEV)
{
if (linkSpeed < PEAK_LINKSPEED_ETH_1G)
{
// camera running with 100 Mbit/s or lower
}
else
{
// camera running with 1 Gbit/s or higher
}
}

Throughput

The throughput has the following parameters:

ThroughputFrameRateLimit

Specifies the maximum frame rate achievable with the bandwidth set by ThroughputLimit.

ThroughputCalculated

The calculated theoretical bandwidth for the data stream based on current settings, but actual bandwidth is limited by the ThroughputLimit.

ThroughputLimit

Sets an upper limit to the bandwidth for data sent from the camera. For GigE Vision cameras, it calculates packet delays and the maximum achievable frame rate. For USB 3 cameras, it can make data transfer via USB2 possible but may reduce sensor readout speed and increase rolling shutter effects, especially with high image widths. In general, using the ThroughputLimit allows precise and intuitive bandwidth control, ensuring optimal data transfer rates while balancing performance and stability.

Note
It is advised to reserve a small portion of bandwidth for packet resends and commands on the control channel.

The following sample sets the throughput limit to half the possible value and sets the corresponding framerate if it is supported by the camera model:

peak_access_status access = peak_Bandwidth_ThroughputLimit_GetAccessStatus(hCam);
if (access != PEAK_ACCESS_READWRITE)
{
return;
}
int64_t min = 0, max = 0, inc = 0;
peak_status status = peak_Bandwidth_ThroughputLimit_GetRange(hCam, &min, &max, &inc);
if (PEAK_ERROR(status))
{
return;
}
int64_t halfValue = max / 2;
halfValue -= halfValue % inc;
status = peak_Bandwidth_ThroughputLimit_Set(hCam, halfValue);
if (PEAK_ERROR(status))
{
return;
}
access = peak_Bandwidth_ThroughputFrameRateLimit_GetAccessStatus(hCam);
if (PEAK_IS_READABLE(access))
{
double maxFrameRate = 0.0;
status = peak_Bandwidth_ThroughputFrameRateLimit_Get(hCam, &maxFrameRate);
if (PEAK_ERROR(status))
{
return;
}
status = peak_FrameRate_Set(hCam, maxFrameRate * 0.95);
if (PEAK_ERROR(status))
{
return;
}
}

peak_status peak_Bandwidth_LinkSpeed_Get ( peak_camera_handle hCam,
int64_t * linkSpeed_Bps )

Get the link speed.

Read the maximum data transfer rate negotiated between the camera and the network after connection. For a list of possible values see Link speed constants.

This value is informative only and shouldn't be set with peak_Bandwidth_ThroughputLimit_Set

Parameters
[in]hCamThe camera handle.
[out]linkSpeed_BpsThe link speed in bytes per second.
Returns
PEAK_STATUS_SUCCESS Operation was successful; no error occurred.
PEAK_STATUS_ACCESS_DENIED The link speed control is not available for read access. Check the access status via peak_Bandwidth_LinkSpeed_GetAccessStatus.
PEAK_STATUS_INVALID_PARAMETER linkSpeed_Bps is an invalid pointer.
PEAK_STATUS_INVALID_HANDLE hCam is an invalid camera handle.
PEAK_STATUS_NOT_INITIALIZED The library is not initialized.
PEAK_STATUS_ERROR An unexpected internal error occurred.

Query the link speed access status.

Provides the current access status for the link speed control.

This function implements the Access Status Query principle.

Parameters
[in]hCamThe camera handle.
Returns
PEAK_ACCESS_READWRITE The link speed control is readable and writeable.
PEAK_ACCESS_READONLY The link speed control is readable only.
PEAK_ACCESS_GFA_LOCK The link speed control is not accessible because the GFA write access is enabled.
PEAK_ACCESS_NONE The link speed control is not accessible.
PEAK_ACCESS_NOT_SUPPORTED The link speed control is not supported.
PEAK_ACCESS_INVALID The function failed. Call peak_Library_GetLastError to get the error code and description.

If the function indicates an error by returning PEAK_ACCESS_INVALID, these are the possible errors:

  • PEAK_STATUS_INVALID_HANDLE hCam is an invalid camera handle.
  • PEAK_STATUS_NOT_INITIALIZED The library is not initialized.
  • PEAK_STATUS_ERROR An unexpected internal error occurred.
