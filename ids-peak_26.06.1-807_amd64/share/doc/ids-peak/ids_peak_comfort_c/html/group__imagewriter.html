Detailed Description

ImageWriter saves images to a file. Multiple ImageWriter objects can be configured to specify image file format and compression ratio.

Note
If only an 'ImageWriter' is created without configuring the default image format is PNG with a compression ratio of 25.

The following image formats are supported:

  • Portable Network Graphics (PNG)
  • Bitmap (BMP)
  • Joint Photographic Experts Group (JPEG)
  • Tag Image File Format (TIFF)
  • Raw Binary Format (RAW)

The image is saved via peak_IPL_ImageWriter_Save with specified file path and file name.

Note
The file extension for the given file name must match the specified image format when a image is saved. Otherwise an error will occur when saving an image. The file extensions are:
  • PNG: .png
  • BMP: .bmp
  • JPEG: .jpeg
  • TIFF: .tiff

It is also possible to save an image without the ImageWriter. See peak_Frame_Save for more information.

Note
The Compression ratio is only used for PNG and JPEG file formats.

Supported image and pixel formats

Bitmap

Not all image formats can be written to a Bitmap file. Supported image formats are:

  • Mono8
  • Mono10
  • Mono12
  • RGB8
  • BGR8
  • RGBa8
  • BGRa8

Written as Mono:

  • BayerGR8, BayerRG8, BayerGB8, BayerBG8
  • BayerGR10, BayerRG10, BayerGB10, BayerBG10
  • BayerGR12, BayerRG12, BayerGB12, BayerBG12

PNG

Not all image formats can be written to a PNG file. Supported image formats are:

  • Mono8
  • Mono10
  • Mono12
  • RGB8
  • RGB10
  • RGB12
  • RGBa8
  • RGBa10
  • RGBa12

Written as Mono:

  • BayerGR8, BayerRG8, BayerGB8, BayerBG8
  • BayerGR10, BayerRG10, BayerGB10, BayerBG10,
  • BayerGR12, BayerRG12, BayerGB12, BayerBG12

Written as RGB:

  • BGR8
  • BGR10
  • BGR12
  • BGRa8
  • BGRa10
  • RGBa12
Note
For PNG image format higher compression rates result in higher storage times and cpu utilization.

TIFF

Not all image formats can be written to a TIFF file. Unsupported images formats are all packed image formats, YUV, all formats with alpha channel and all BGR pixel formats.

JPEG

Not all image formats can be written to a JPEG file. Supported image formats are:

  • Mono8
  • RGB8
  • BGR8
  • RGBa8
  • BGRa8

Written as Mono:

  • BayerGR8, BayerRG8, BayerGB8, BayerBG8
Note
For JPEG image format higher compression rates result in lower quality image. A compression ratio of 0 means a maximum of image quality.

RAW

Writes the specified image to the filesystem as a raw binary image. This is supported for all non-packed pixel formats.

Examples

Note
To reduce and simplify the sample code, the examples do not check the return values.

Configure a PNG ImageWriter with high compression

peak_imagewriter_handle image_writer_handle = PEAK_INVALID_HANDLE;
peak_IPL_ImageWriter_Create(&image_writer_handle);
peak_IPL_ImageWriter_Format_Set(image_writer_handle, PEAK_IMAGEFILE_FORMAT_PNG);
peak_IPL_ImageWriter_Compression_Set(image_writer_handle, 80);
peak_IPL_ImageWriter_Save(image_writer_handle, hFrame, "out.png");
peak_IPL_ImageWriter_Destroy(image_writer_handle);
