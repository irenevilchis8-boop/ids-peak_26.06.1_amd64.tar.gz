Detailed Description

A burst trigger is a feature that allows the camera to capture multiple images in quick succession after receiving a single trigger signal.

Once activated, the camera captures a predefined number of frames in a "burst" before stopping, without requiring additional trigger signals. This is useful for high-speed imaging applications where capturing a series of images in rapid succession is needed.

◆ peak_Trigger_Burst_GetAccessStatus()

peak_access_status peak_Trigger_Burst_GetAccessStatus ( peak_camera_handle hCam)

Query the trigger burst property access status.

Provides the current access status for the trigger burst property for the configured trigger mode.

This function implements the Access Status Query principle.

Parameters
[in]hCamThe camera handle.
Returns
PEAK_ACCESS_READWRITE The trigger burst property is readable and writeable.
PEAK_ACCESS_READONLY The trigger burst property is readable only.
PEAK_ACCESS_GFA_LOCK The trigger burst property is not accessible because the GFA write access is enabled.
PEAK_ACCESS_NONE The trigger burst property is not accessible.
PEAK_ACCESS_NOT_SUPPORTED The trigger burst property is not supported.
PEAK_ACCESS_INVALID The function failed. Call peak_Library_GetLastError to get the error code and description.

If the function indicates an error by returning PEAK_ACCESS_INVALID, these are the possible errors:

  • PEAK_STATUS_ACCESS_DENIED The trigger feature is not accessible. Check the access status of the trigger feature via peak_Trigger_GetAccessStatus.
  • PEAK_STATUS_INVALID_HANDLE hCam is an invalid camera handle.
  • PEAK_STATUS_NOT_INITIALIZED The library is not initialized.
  • PEAK_STATUS_ERROR An unexpected internal error occurred.
