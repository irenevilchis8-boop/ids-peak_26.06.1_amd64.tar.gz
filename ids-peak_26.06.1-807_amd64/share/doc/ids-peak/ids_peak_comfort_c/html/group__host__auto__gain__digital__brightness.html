Detailed Description

Auto brightness gain digital control related functions and types.

This feature is applied in the host.
There is also a camera implementation. See Auto brightness control.

◆ peak_IPL_AutoBrightness_GainDigitalLimit_Set()

peak_status peak_IPL_AutoBrightness_GainDigitalLimit_Set ( peak_camera_handle hCam,
peak_double_limit gainLimit )

Set the host auto gain digital limit.

The valid values can be read out by calling peak_IPL_AutoBrightness_GainDigitalLimit_GetRange. Default is the complete range.

If any value of the limit is out of range, the value is clamped to be valid. In this case the functions returns with PEAK_STATUS_VALUE_ADJUSTED. It is recommended to check the current values by calling peak_IPL_AutoBrightness_GainDigitalLimit_Get after this call.

Parameters
[in]hCamThe camera handle.
[in]gainLimitThe gain limit to set.
Returns
PEAK_STATUS_SUCCESS Operation was successful; no error occurred.
PEAK_STATUS_INVALID_PARAMETER gainLimit is an invalid pointer.
PEAK_STATUS_INVALID_HANDLE hCam is an invalid camera handle.
PEAK_STATUS_NOT_INITIALIZED The library is not initialized.
PEAK_STATUS_VALUE_ADJUSTED At least one value of the limit is out of range. The limit was adjusted accordingly.
PEAK_STATUS_ERROR An unexpected internal error occurred.
Since
1.9
