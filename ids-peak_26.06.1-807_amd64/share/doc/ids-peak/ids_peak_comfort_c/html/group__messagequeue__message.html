peak_status peak_Message_CameraHandle_Get ( peak_message_handle hMessage,
peak_camera_handle * hCam )

Get the camera handle for a message.

May be PEAK_INVALID_HANDLE if no camera is associated with the message.

Parameters
[in]hMessageHandle for a message instance.
[out]hCamThe camera handle of the origin camera or PEAK_INVALID_HANDLE if origin is not the camera e.g. the camera manager.
Returns
PEAK_STATUS_SUCCESS Operation was successful; no error occurred.
PEAK_STATUS_INVALID_HANDLE hMessage is an invalid handle.
PEAK_STATUS_INVALID_PARAMETER hCam is an invalid pointer.
PEAK_STATUS_NOT_INITIALIZED The library is not initialized.
PEAK_STATUS_ERROR An unexpected internal error occurred.
Since
1.5

peak_status peak_Message_HostTimestamp_Get ( peak_message_handle hMessage,
uint64_t * hostTimestamp_ns )

Get the host timestamp for a message.

This timestamp is in nanoseconds and originates from the system clock. It represents time since epoch e.g. on most systems this means Unix Time.
