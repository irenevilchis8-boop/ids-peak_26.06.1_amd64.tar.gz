Detailed Description

Digital black is a technique used in image processing to adjust the black point before gamma correction is applied. Gamma correction often causes dark areas of an image to appear gray by lifting the overall brightness and redistributing tonal values. By pulling down the black point with digital black, the noisy pixels are eliminated first so the gamma correction does not multiply the noise.

Note
This feature is only applied in the host.

Example to use the digital black feature:

double min = 0.0;
double max = 0.0;
// Get the range of valid values for digital black
peak_status status = peak_IPL_DigitalBlack_GetRange(hCam, &min, &max);
if (PEAK_ERROR(status))
{
// handle error
}
// Set a digital black value
status = peak_IPL_DigitalBlack_Set(hCam, 0.05);
if (PEAK_ERROR(status))
{
// handle error
}
// Get current digital black value
double value = 0.0;
status = peak_IPL_DigitalBlack_Get(hCam, &value);
if (PEAK_ERROR(status))
{
// handle error
}
