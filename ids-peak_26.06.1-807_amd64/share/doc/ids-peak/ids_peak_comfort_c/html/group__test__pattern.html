◆ peak_TestPattern_GetAccessStatus()

peak_access_status peak_TestPattern_GetAccessStatus ( peak_camera_handle hCam)

Query the test pattern access status.

Provides the current access status for the test pattern control.

This function implements the Access Status Query principle.

Parameters
[in]hCamThe camera handle.
Returns
PEAK_ACCESS_READWRITE The test pattern control is readable and writeable.
PEAK_ACCESS_READONLY The test pattern control is readable only.
PEAK_ACCESS_GFA_LOCK The test pattern control is not accessible because the GFA write access is enabled.
PEAK_ACCESS_NONE The test pattern control is not accessible.
PEAK_ACCESS_NOT_SUPPORTED The test pattern control is not supported.
PEAK_ACCESS_INVALID The function failed. Call peak_Library_GetLastError to get the error code and description.

If the function indicates an error by returning PEAK_ACCESS_INVALID, these are the possible errors:

  • PEAK_STATUS_INVALID_HANDLE hCam is an invalid camera handle.
  • PEAK_STATUS_NOT_INITIALIZED The library is not initialized.
  • PEAK_STATUS_ERROR An unexpected internal error occurred.
Since
1.9

◆ peak_TestPattern_GetList()

peak_status peak_TestPattern_GetList ( peak_camera_handle hCam,
peak_test_pattern * testPatternList,
size_t * testPatternCount )

Get the list of currently usable test pattern.

Queries the list of currently selectable test pattern.

The list of usable parameter sets may depend on the camera configuration and the camera status.

This function implements the Two Staged Data Query principle.

Parameters
[in]hCamThe camera handle.
[out]testPatternListPointer to a user allocated array buffer to receive the parameter set list. If this parameter is NULL, testPatternCount will contain the current number of parameter sets.
The required size of testPatternList in bytes is testPatternCount x sizeof(peak_test_pattern).
[in,out]testPatternCount
  • testPatternList equal NULL:
    out: minimal number of test patterns testPatternList must be large enough to hold
  • testPatternList unequal NULL:
    in: number of test patterns testPatternList can hold
    out: number of test patterns filled by the function
Returns
PEAK_STATUS_SUCCESS Operation was successful; no error occurred.
PEAK_STATUS_BUFFER_TOO_SMALL testPatternList is not NULL and the value of *testPatternCount is too small to receive the expected amount of data.
PEAK_STATUS_ACCESS_DENIED The test pattern feature is not supported or the GFA write mode is enabled.
PEAK_STATUS_INVALID_PARAMETER testPatternCount is an invalid pointer.
PEAK_STATUS_INVALID_HANDLE hCam is an invalid camera handle.
PEAK_STATUS_NOT_INITIALIZED The library is not initialized.
PEAK_STATUS_ERROR An unexpected internal error occurred.
Since
1.9
