Detailed Description

Controls the behavior of the selected camera LED.

Example to use the LED control feature:

if (peak_LED_GetAccessStatus(hCam) == PEAK_ACCESS_READWRITE)
{
peak_led_target target = PEAK_LED_TARGET_STATUS;
size_t ledModeCount = 0;
peak_status status = peak_LED_Mode_GetList(hCam, target, NULL, &ledModeCount);
if (PEAK_SUCCESS(status) && ledModeCount != 0)
{
peak_led_mode* ledModes = (peak_led_mode*)malloc(
ledModeCount * sizeof(peak_led_mode));
status = peak_LED_Mode_GetList(hCam, target, ledModes, &ledModeCount);
if (PEAK_SUCCESS(status))
{
// do something with ledModes
}
free(ledModes);
}
}

◆ peak_LED_GetAccessStatus()

peak_access_status peak_LED_GetAccessStatus ( peak_camera_handle hCam)

Query LED access status.

Provides the current access status for the LED feature.

This function implements the Access Status Query principle.

Parameters
[in]hCamThe camera handle.
Returns
PEAK_ACCESS_READWRITE The LED feature is readable and writeable.
PEAK_ACCESS_READONLY The LED feature is readable only.
PEAK_ACCESS_GFA_LOCK The LED feature is not accessible because the GFA write access is enabled.
PEAK_ACCESS_NONE The LED feature is not accessible.
PEAK_ACCESS_NOT_SUPPORTED The LED feature is not supported.
PEAK_ACCESS_INVALID The function failed. Call peak_Library_GetLastError to get the error code and description.

If the function indicates an error by returning PEAK_ACCESS_INVALID, these are the possible errors:

  • PEAK_STATUS_INVALID_HANDLE hCam is an invalid camera handle.
  • PEAK_STATUS_NOT_INITIALIZED The library is not initialized.
  • PEAK_STATUS_ERROR An unexpected internal error occurred.

1.9

◆ peak_LED_Mode_GetList()

peak_status peak_LED_Mode_GetList ( peak_camera_handle hCam,
peak_led_target target,
peak_led_mode * modeList,
size_t * ledModeCount )

Get the list of currently usable LED modes of the specified LED target.

Queries the list of currently selectable LED modes.

The list of usable LED modes may depend on the LED target, the camera configuration and the camera status.

This function implements the Two Staged Data Query principle.

Parameters
[in]hCamThe camera handle.
[in]targetThe LED target
[out]modeListPointer to a user allocated array buffer to receive the LED mode list. If this parameter is NULL, *ledModeCount will contain the current number of LED modes.
The required size of modeList in bytes is ledModeCount x sizeof(peak_led_mode).
[in,out]ledModeCount
  • modeList equal NULL:
    out: minimal number of LED modes modeList must be large enough to hold
  • modeList unequal NULL:
    in: number of LED modes modeList can hold
    out: number of LED modes filled by the function
Returns
PEAK_STATUS_SUCCESS Operation was successful; no error occurred.
PEAK_STATUS_BUFFER_TOO_SMALL modeList is not NULL and the value of *ledModeCount is too small to receive the expected amount of data.
PEAK_STATUS_ACCESS_DENIED The LED feature is not supported or the GFA write mode is enabled.
PEAK_STATUS_INVALID_PARAMETER ledModeCount is an invalid pointer.
PEAK_STATUS_INVALID_HANDLE hCam is an invalid camera handle.
PEAK_STATUS_NOT_INITIALIZED The library is not initialized.
PEAK_STATUS_ERROR An unexpected internal error occurred.
Since
1.9
