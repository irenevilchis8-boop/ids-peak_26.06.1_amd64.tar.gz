◆ peak_DecimationManual_FactorX_GetList()

peak_status peak_DecimationManual_FactorX_GetList ( peak_camera_handle hCam,
peak_subsampling_engine subsamplingEngine,
uint32_t * decimationFactorXList,
size_t * decimationFactorXCount )

Get the list of currently selectable factors for the decimation in x direction.

Queries the list of currently selectable decimation factors in x direction for the given subsampling engine.

The list of selectable decimation factors may depend on the camera configuration and the camera status.

This function implements the Two Staged Data Query principle.

Parameters
[in]hCamThe camera handle.
[in]subsamplingEngineThe engine for the subsampling algorithm.
[out]decimationFactorXListPointer to a user allocated array buffer to receive the decimation factor list. If this parameter is NULL, decimationFactorXCount will contain the current number of decimation factors.
The required size of decimationFactorXList in bytes is decimationFactorXCount x sizeof(uint32_t).
[in,out]decimationFactorXCount
  • decimationFactorXList equal NULL:
    out: minimal number of decimation factors decimationFactorXList must be large enough to hold
  • decimationFactorXList unequal NULL:
    in: number of decimation factors decimationFactorXList can hold
    out: number of decimation factors filled by the function
Returns
PEAK_STATUS_SUCCESS Operation was successful; no error occurred.
PEAK_STATUS_BUFFER_TOO_SMALL decimationFactorXList is not NULL and the value of *decimationFactorXCount is too small to receive the expected amount of data.
PEAK_STATUS_ACCESS_DENIED The decimation feature is not accessible. Check the access status via peak_DecimationManual_GetAccessStatus.
PEAK_STATUS_INVALID_PARAMETER decimationFactorXCount is an invalid pointer.
PEAK_STATUS_INVALID_HANDLE hCam is an invalid camera handle.
PEAK_STATUS_NOT_INITIALIZED The library is not initialized.
PEAK_STATUS_ERROR An unexpected internal error occurred.
Note
Consider that the decimation factor list might change between the size query call and the list query call.
This may be the case if the camera configuration or the camera status have changed in the time between the two function calls.
Since
1.10

◆ peak_DecimationManual_GetAccessStatus()

peak_access_status peak_DecimationManual_GetAccessStatus ( peak_camera_handle hCam,
peak_subsampling_engine subsamplingEngine )

Query the decimation manual access status.

Provides the current access status for the decimation feature for the given subsampling engine.

This function implements the Access Status Query principle.

Parameters
[in]hCamThe camera handle.
[in]subsamplingEngineThe engine for the subsampling algorithm.
Returns
PEAK_ACCESS_READWRITE The decimation feature is readable and writeable.
PEAK_ACCESS_READONLY The decimation feature is readable only.
PEAK_ACCESS_GFA_LOCK The decimation feature is not accessible because the GFA write access is enabled.
PEAK_ACCESS_NONE The decimation feature is not accessible.
PEAK_ACCESS_NOT_SUPPORTED The decimation feature is not supported.
PEAK_ACCESS_INVALID The function failed. Call peak_Library_GetLastError to get the error code and description.

If the function indicates an error by returning PEAK_ACCESS_INVALID, these are the possible errors:

  • PEAK_STATUS_INVALID_HANDLE hCam is an invalid camera handle.
  • PEAK_STATUS_NOT_INITIALIZED The library is not initialized.
  • PEAK_STATUS_ERROR An unexpected internal error occurred.
Since
1.10

Set the decimation factors.

Writes the desired decimation factors for the given subsampling engine.

Returns

PEAK_STATUS_VALUE_ADJUSTED At least one of the values was automatically adjusted. Check the effective values via peak_DecimationManual_Get.
PEAK_STATUS_OUT_OF_RANGE decimationFactorX and/or decimationFactorY are out of range. Check the range of valid values via peak_DecimationManual_FactorX_GetList and peak_DecimationManual_FactorY_GetList.
PEAK_STATUS_ACCESS_DENIED The binning feature is not available for write access. Check the access status via peak_DecimationManual_GetAccessStatus.
PEAK_STATUS_INVALID_HANDLE hCam is an invalid camera handle.
PEAK_STATUS_NOT_INITIALIZED The library is not initialized.
PEAK_STATUS_ERROR An unexpected internal error occurred.
