Detailed Description

Chunks refer to blocks of metadata transmitted alongside image data.

These chunks contain information about the camera’s settings and operation, such as exposure time, gain, timestamps, and other control parameters.

They help provide context to the image data, allowing for more accurate processing and analysis. Chunks can be enabled or disabled as needed to optimize data transmission.

To use chunks the following steps are needed:

  • Check for support
  • Enable the chunks transmission
  • Check for supported types
  • Enable a type
  • Select the update mode
  • Acquire frame(s)
  • Retrieve chunk data

Check for support

Before using chunks, a check for support is advised as support depends on the camera type and version. Note that the PEAK_CAMERA_TYPE_UEYE_USB and PEAK_CAMERA_TYPE_UEYE_ETH cameras do not support chunks at all.

peak_access_status accessStatus = peak_Chunks_GetAccessStatus(hCam);
if (!PEAK_IS_SUPPORTED(accessStatus))
{
// error handling
}
// chunks are supported

Enable the chunks transmission

In the camera, the chunks transmission must be enabled before they are used:

if (PEAK_ERROR(peak_Chunks_Enable(hCam, PEAK_TRUE)))
{
// error handling
}
// chunks are enabled

Check for supported types

The support of each type depends on the camera support. To check for support, either use peak_Chunks_Type_GetAccessStatus or iterate through the list of supported types:

size_t size = 0;
if (PEAK_ERROR(peak_Chunks_Type_Supported_GetList(hCam, NULL, &size)))
{
// error handling
return;
}
peak_chunks_type* supportedList = (peak_chunks_type*)malloc(size * sizeof(peak_chunks_type));
if (supportedList == NULL)
{
// error handling
return;
}
if (PEAK_ERROR(peak_Chunks_Type_Supported_GetList(hCam, supportedList, &size)))
{
// error handling
free(supportedList);
return;
}
for (size_t i = 0; i < size; i++)
{
//do something e.g., filter, check for support
}
free(supportedList);

Enable a type

Enable a specific chunk type to receive it. This is done here for PEAK_CHUNKS_TYPE_TIMESTAMP as an example:

// Enable the timestamp chunk
if (PEAK_ERROR(peak_Chunks_Type_Enable(hCam, PEAK_CHUNKS_TYPE_TIMESTAMP, PEAK_TRUE)))
{
// error handling
}

Update Mode

There are two ways in which the chunks can be updated. The mode can be changed by a call to peak_Chunks_AutoUpdate_Enable.

Note
The chunk data is cached. If chunks were enabled before this, older data may still be available.

Auto Update

This is the default mode.

With each call to peak_Acquisition_WaitForFrame the chunks are automatically updated if the frame contains chunk data.

Note
Chunk data for older frames can still be retrieved if peak_Chunks_Update is called beforehand.

Manual Update

In manual mode, the update must be carried out by a call to peak_Chunks_Update.

Acquire frame(s)

Start the image acquisition with peak_Acquisition_Start and wait for a frame with peak_Acquisition_WaitForFrame.

Retrieve chunk data

Each of the chunk type has a corresponding function for data retrieval. These are:

This is done as an example for peak_Chunks_Timestamp_Get, as shown below. The other types and their functions are interchangeable:

// Start the acquisition normally
if (PEAK_ERROR(peak_Acquisition_Start(hCam, PEAK_INFINITE)))
{
// error handling
return;
}
// Get 10 frames
for (int i = 0; i < 10; i++)
{
peak_frame_handle hFrame = PEAK_INVALID_HANDLE;
peak_chunks_timestamp timestampChunk = { 0 };
// Wait for the frame. Before returning, the chunks will be updated.
if (PEAK_ERROR(peak_Acquisition_WaitForFrame(hCam, 1000, &hFrame)))
{
printf("Could not get frame %d\n", i);
continue;
}
// Get the timestamp chunk and print it
if (PEAK_SUCCESS(peak_Chunks_Timestamp_Get(hCam, &timestampChunk)))
{
printf("Timestamp for frame %d: %"PRIi64"\n", i, timestampChunk.timestamp);
}
else
{
printf("Could not get timestamp chunk data for frame %d", i);
}
if (PEAK_ERROR(peak_Frame_Release(hCam, hFrame)))
{
// error handling
}
}
if (PEAK_ERROR(peak_Acquisition_Stop(hCam)))
{
// error handling
}

If newer chunk types that are not supported by the current API version are required, they can be enabled and retrieved using the GFA interface.

peak_status peak_Chunks_AutoFeature_Get ( peak_camera_handle hCam,
peak_chunks_autofeature * data )

Retrieves the auto-feature information from chunk data.

This includes the status of the auto brightness and the auto white balance features. If the camera does not support all auto features, the corresponding status will be PEAK_AUTO_FEATURE_STATUS_INVALID.

Parameters
[in]hCamThe camera handle.
[out]dataPointer of type peak_chunks_autofeature where the auto feature information will be stored.
Returns
PEAK_STATUS_SUCCESS Operation was successful; auto-feature information retrieved.
PEAK_STATUS_INVALID_HANDLE The camera handle hCam is invalid.
PEAK_STATUS_NOT_INITIALIZED The library has not been initialized.
PEAK_STATUS_NOT_IMPLEMENTED The chunk type is not available. Check support with peak_Chunks_Type_GetAccessStatus.
PEAK_STATUS_ACCESS_DENIED The data for the chunk type is not readable. Check that the chunk mode is enabled, the chunk type is enabled and that the frame data is processed by either enabling auto update or a call to peak_Chunks_Update.
PEAK_STATUS_ERROR An unexpected internal error occurred.
Since
1.13

◆ peak_Chunks_AutoUpdate_Enable()

peak_status peak_Chunks_AutoUpdate_Enable ( peak_camera_handle hCam,
peak_bool enabled )

Control whether the chunks auto update is enabled or disabled.

This changes the behavior when the chunks are updated:

  • When auto update is enabled, the chunks are updated with each call to peak_Acquisition_WaitForFrame.
  • When auto update is disabled, the chunks must be updated by calling peak_Chunks_Update.
Parameters
[in]hCamThe camera handle.
[in]enabledThe desired auto update status. PEAK_TRUE for enabled, PEAK_FALSE for disabled.
Returns
PEAK_STATUS_SUCCESS Operation was successful; no error occurred.
PEAK_STATUS_ACCESS_DENIED Chunks are not available. Check the access status via peak_Chunks_GetAccessStatus.
PEAK_STATUS_INVALID_HANDLE hCam is an invalid camera handle.
PEAK_STATUS_NOT_INITIALIZED The library is not initialized.
PEAK_STATUS_ERROR An unexpected internal error occurred.
Since
1.13

◆ peak_Chunks_GetAccessStatus()

peak_access_status peak_Chunks_GetAccessStatus ( peak_camera_handle hCam)

Query the chunks access status.

This function implements the Access Status Query principle.

Parameters
[in]hCamThe camera handle.
Returns
PEAK_ACCESS_READWRITE The feature is available for read access and for write access.
PEAK_ACCESS_READONLY The feature is supported but not available for change.
PEAK_ACCESS_NOT_SUPPORTED The feature is not supported.
PEAK_ACCESS_NONE The feature is not available.
PEAK_ACCESS_INVALID The function failed. Call peak_Library_GetLastError to get the error code and description.

If the function indicates an error by returning PEAK_ACCESS_INVALID, these are the possible errors:

  • PEAK_STATUS_NOT_INITIALIZED The library is not initialized.
  • PEAK_STATUS_ERROR An unexpected internal error occurred.
