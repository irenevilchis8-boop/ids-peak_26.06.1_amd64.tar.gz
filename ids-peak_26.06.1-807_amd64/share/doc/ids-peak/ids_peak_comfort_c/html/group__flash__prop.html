Detailed Description

Functions to set the flash timing parameters.

Contains the functions to control the flash configuration options flash duration flash start delay flash end delay.

The flash duration is the time the flash is on. It is based on the flash reference in the peak_flash_mode set by peak_Flash_Mode_Set. The duration can be lengthened or shortened at the beginning using the flash start delay, and at the end using the flash end delay. Changing the flash mode will reset both the flash start and end delays. On some cameras, the flash duration can also be manually set via peak_Flash_Duration_Set.

◆ peak_Flash_Duration_GetAccessStatus()

peak_access_status peak_Flash_Duration_GetAccessStatus ( peak_camera_handle hCam)

Query the flash duration property access status.

Provides the current access status for the flash duration property for the configured flash mode.

This function implements the Access Status Query principle.

Parameters
[in]hCamThe camera handle.
Returns
PEAK_ACCESS_READWRITE The flash duration property is readable and writeable.
PEAK_ACCESS_READONLY The flash duration property is readable only.
PEAK_ACCESS_GFA_LOCK The flash duration property is not accessible because the GFA write access is enabled.
PEAK_ACCESS_NONE The flash duration property is not accessible.
PEAK_ACCESS_NOT_SUPPORTED The flash duration property is not supported.
PEAK_ACCESS_INVALID The function failed. Call peak_Library_GetLastError to get the error code and description.

If the function indicates an error by returning PEAK_ACCESS_INVALID, these are the possible errors:

  • PEAK_STATUS_ACCESS_DENIED The flash feature is not accessible. Check the access status of the flash feature via peak_Flash_GetAccessStatus.
  • PEAK_STATUS_INVALID_HANDLE hCam is an invalid camera handle.
  • PEAK_STATUS_NOT_INITIALIZED The library is not initialized.
  • PEAK_STATUS_ERROR An unexpected internal error occurred.
Since
1.0
