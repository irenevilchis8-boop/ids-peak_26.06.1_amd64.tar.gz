◆ peak_loss_handling_mode

enum peak_loss_handling_mode

peak Loss handling modes

Enumerator
PEAK_LOSS_HANDLING_MODE_INVALID 

Invalid loss handling mode.

Use this value for the initialization of variables of type peak_loss_handling_mode.

PEAK_LOSS_HANDLING_MODE_OFF 

Loss handling mode off.

Loss handling is disabled.

PEAK_LOSS_HANDLING_MODE_LIMITED 

Loss handling mode limited.

If packets are missing, a resend request is sent to the device. The number of packets that can be resent is limited by Loss Handling Extent. Each packet can be resent only once.

PEAK_LOSS_HANDLING_MODE_UNLIMITED 

Loss handling mode unlimited.

If packets are missing, a resend request is sent to the device. The number of packets that can be resent is limited by the camera's buffering capabilities.

peak_status peak_Acquisition_LossHandling_Mode_GetList ( peak_camera_handle hCam,
peak_loss_handling_mode * lossHandlingModeList,
size_t * lossHandlingModesCount )

Get the list of currently usable loss handling modes.

Queries the list of currently selectable loss handling modes.

The list of usable loss handling modes may depend on the camera configuration and interface technology.

This function implements the Two Staged Data Query principle.

Parameters
[in]hCamThe camera handle.
[out]lossHandlingModeListPointer to a user allocated array buffer to receive the loss handling mode list. If this parameter is NULL, lossHandlingModesCount will contain the current number of loss handling modes.
The required size of lossHandlingModeList in bytes is lossHandlingModesCount x sizeof(peak_loss_handling_mode).
[in,out]lossHandlingModesCount
  • lossHandlingModeList equal NULL:
    out: minimal number of loss handling modes lossHandlingModeList must be large enough to hold
  • lossHandlingModeList unequal NULL:
    in: number of loss handling modes lossHandlingModeList can hold
    out: number of loss handling modes filled by the function
Returns
PEAK_STATUS_SUCCESS Operation was successful; no error occurred.
PEAK_STATUS_BUFFER_TOO_SMALL lossHandlingModeList is not NULL and the value of *lossHandlingModesCount is too small to receive the expected amount of data.
PEAK_STATUS_ACCESS_DENIED The loss handling mode feature is not supported or the GFA write mode is enabled.
PEAK_STATUS_INVALID_PARAMETER lossHandlingModesCount is an invalid pointer.
PEAK_STATUS_INVALID_HANDLE hCam is an invalid camera handle.
PEAK_STATUS_NOT_INITIALIZED The library is not initialized.
PEAK_STATUS_ERROR An unexpected internal error occurred.
Since
1.9
