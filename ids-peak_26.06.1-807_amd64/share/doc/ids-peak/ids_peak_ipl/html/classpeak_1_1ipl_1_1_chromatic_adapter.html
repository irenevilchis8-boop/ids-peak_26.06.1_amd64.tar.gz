Detailed Description

Adjust to changes in lighting conditions to maintain consistent color perception despite variations in light sources.

In industrial imaging, white balance can fail due to the lack of a neutral reference in the image, such as when the scene contains no gray or white areas, or when the colors are unevenly distributed (as in images dominated by a single color). In these cases, traditional white balance algorithms, like the gray world method, may fail to produce accurate color corrections.

Chromatic adaptation provides an alternative solution by adjusting the image’s colors based on the known or estimated correlated color temperature of the light source.

Note
If chromatic adaption is used in combination with white balance, the result is indefinite.

Usage

Recommended Image Processing Pipeline

To ensure proper functioning of chromatic adaptation, it is crucial that the image processing pipeline is designed correctly. Chromatic adaptation should be performed on an image with linear color values, meaning it must occur before gamma correction. However, standardized color spaces require gamma-corrected color values for accurate color reproduction. Furthermore, most cameras require color correction for proper color representation.

As a result, the following image processing pipeline is recommended:

  1. Debayer using the peak::ipl::ImageConverter class.
  2. Color correct with a Color Correction Matrix, modified by the Chromatic Adapter, considering the correlated light temperature of the light source.
  3. Gamma correct with the factor for the target color space
Image Processing Pipeline

Configuration

The image pipeline can be configured before image processing begins. The sample code below shows how the necessary modules are set up to process images for the target color space sRGB D65, where the scene is illuminated by a light source with a correlated color temperature of 3600 K.

A gamma corrector is configured with a value of 2.2, which is appropriate for the target color space (sRGB).

The chromatic adapter is set to use the Bradford transform as its algorithm.

The color corrector is initialized with a custom color correction matrix, such as the HQ matrix for the camera's filter glass. Following this, the chromatic adaptation is applied to the matrix using the chromatic adapter and the light source's correlated color temperature of 3600 K.

// prepare the gamma corrector
peak::ipl::GammaCorrector gammaCorrector{};
gammaCorrector.SetGammaCorrectionValue(2.2f);
// configure the chromatic adapter
peak::ipl::ChromaticAdapter chromaticAdapter{};
chromaticAdapter.SetTargetColorSpace(peak::ipl::ChromaticAdapter::ColorSpace::SRGB_D65);
chromaticAdapter.SetAdaptionAlgorithm(peak::ipl::ChromaticAdapter::Algorithm::Bradford);
// configure the color corrector
peak::ipl::ColorCorrector colorCorrector{};
colorCorrector.SetColorCorrectionFactors(ccm);
// apply chromatic adaption
colorCorrector.ApplyChromaticAdaption(chromaticAdapter, 3600);

Alternatively, the adapted color correction matrix can be calculated and applied in two steps. In this case, the second parameter is optional. If not provided, the resulting matrix will be the direct chromatic adaptation matrix.

// apply chromatic adaption
const auto adaptedCcm = chromaticAdapter.CalculateColorCorrectionMatrix(3600, ccm);
colorCorrector.SetColorCorrectionFactors(adaptedCcm);

Image Processing

Each image must be processed following the previously configured image pipeline and in the correct order. It can be processed in-place or by creating a new image, depending on the specific use case.

// 1. debayering
auto image = sourceImage.ConvertTo(peak::ipl::PixelFormatName::RGB8);
// 2. color correction with chromatic adaption
colorCorrector.ProcessInPlace(image);
// 3. gamma correction
gammaCorrector.ProcessInPlace(image);

Terms and Definitions

Color Constancy and Chromatic Adaption

Color constancy is the ability of the human visual system to perceive an object's color consistently, regardless of changes in lighting.

In computer vision, a Chromatic Adaptation Transform (CAT) is a mathematical transformation applied to an image to simulate this perceptual adjustment, ensuring color constancy under varying lighting.

Several algorithms are used to perform CAT, with the Bradford transform being among the most widely used algorithms for this adjustment.

Color Temperature

The correlated color temperature (CCT) describes the color of a visible light source by comparing it to the light emitted by an ideal black body at a specific surface temperature, measured in Kelvin (K).

The following table provides example values:

Light source Color temperature
Light bulb (100 W) 2700 - 2800 K
Halogen lamp 3000 - 3500 K
Daylight (midday sun) 5000 - 6500 K
Cloudy sky 6500 - 7500 K

For artificial light sources, a "white tone" is often specified, which refers to the perceived warmth or coolness of the light. This is opposite to the actual correlated color temperature. Warm light (reddish) has a lower color temperature, while cold light (bluish) has a higher color temperature.

White tone Correlated color temperature
Warm white 2700 - 3500 K
Neutral white 4000 - 5000 K
Cool white 5000 - 6500 K

const ColorCorrectionFactors & correctionFactors = ColorCorrectionFactors::Identity() ) const
inline

Calculate the color correction factors for colorTemperature using the current algorithm and color space.

The optional parameter correctionFactors can be used if the chromatic adaption is to be applied in parallel with another color correction, e.g. the HQ matrix for the camera filter glass. The result will be a matrix multiplication of the initial CCM and the chromatic adaption. It can directly be used. When using the ColorCorrector module, it might be advantageous to adjust an already set CCM using the comfort function ColorCorrector::ApplyChromaticAdaption
