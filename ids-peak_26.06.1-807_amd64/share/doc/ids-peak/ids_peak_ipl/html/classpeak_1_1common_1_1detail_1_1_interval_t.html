Detailed Description

template<typename T>
class peak::common::detail::IntervalT< T >

Represents a continuous numeric interval with inclusive lower and upper bounds.

The interval is defined by two values: a minimum and a maximum. These values must satisfy the condition: minimum <= maximum.

Template Parameters
TMust be an arithmetic type (integer or floating point).
