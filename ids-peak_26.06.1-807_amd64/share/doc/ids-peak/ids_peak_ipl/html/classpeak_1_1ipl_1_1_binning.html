Detailed Description

Performs spatial binning on 2D images.

The Binning class provides a configurable image-processing operation that reduces image resolution by aggregating pixel blocks in the horizontal and/or vertical direction. The aggregation can be performed either by summation or averaging, depending on the selected binning mode. Binning is used to increase signal-to-noise ratio (SNR), improve memory footprint or accelerate downstream image processing steps.
