Detailed Description

Performs spatial decimation on 2D images.

The Decimation class provides a configurable image-processing operation that reduces image resolution by skipping pixel blocks in the horizontal and/or vertical direction. Decimation is used to improve memory footprint or accelerate downstream image processing steps.
