Detailed Description

template<typename T>
class peak::common::detail::SizeT< T >

Represents a two-dimensional size with non-negative width and height.

A SizeT stores the width and height of an object or area. Both dimensions must be greater than or equal to zero.

Template Parameters
TArithmetic type used for width and height.
