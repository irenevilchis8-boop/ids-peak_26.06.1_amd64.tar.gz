Detailed Description

C-compatible types for interoperability with C codebases.

This group contains a selection of type definitions and structures designed for use in pure C environments. While the majority of the library is written in C++ and leverages modern C++ features, these types provide limited interoperability for scenarios where integration with C code is required.

Only a subset of types are exposed in this group, focused on facilitating basic data exchange and interoperability. Full functionality of the library is not available in C.
