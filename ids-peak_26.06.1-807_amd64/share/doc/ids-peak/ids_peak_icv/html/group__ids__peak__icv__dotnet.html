Detailed Description

The .NET interface for the IDS peak ICV library.

The interface is delivered as a package via NuGet. It can be installed using the .NET CLI:

dotnet add package IDSImaging.Peak.ICV

To use IDS peak ICV in your project, include the IDSImaging.Peak.ICV namespace by adding:

using IDSImaging.Peak.ICV;

Resource Management (IDisposable)

Because this .NET library acts as a wrapper around a native C backend, many classes allocate and manage unmanaged memory (e.g., image buffers). To ensure deterministic release of these native resources and prevent memory leaks, these classes implement the standard IDisposable interface. You must dispose of these objects as soon as they are no longer needed. The safest and cleanest way to do this is by utilizing the C# using declaration:

using var module = new DefaultPipeline();
// ... use the module ...
// The native resources are automatically freed at the end of the current scope.

For more details, refer to the Microsoft documentation.
