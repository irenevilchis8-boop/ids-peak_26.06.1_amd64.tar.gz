Detailed Description

Provides functionality for painting drawable objects on images.

The Painter enables rendering of objects derived from IDrawable onto images. Supported image formats are RGB8, BGR8, RGBa8, and BGRa8.

You can configure drawing properties such as color and opacity using Color and Opacity. If not explicitly configured, default values from DrawingOptions are applied.

var painter = new Painter(image);
painter.Color = new Color(ColorConstant.BLUE);
painter.Opacity = new Opacity(50);
painter.Draw(region);
