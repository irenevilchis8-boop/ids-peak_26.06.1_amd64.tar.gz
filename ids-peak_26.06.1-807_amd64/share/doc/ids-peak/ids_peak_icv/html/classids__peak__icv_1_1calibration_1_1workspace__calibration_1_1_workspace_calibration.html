Detailed Description

Class for calibrating a workspace.

The WorkspaceCalibration calculates the extrinsic parameters based on a single image.

◆ process()

CalibrationResult process ( self,
Union[Image, ids_peak_ipl.Image] image )

Applies the workspace calibration and calculates the extrinsic camera parameters based on a single view of a calibration pattern.

Furthermore, it computes the mean reprojection error.

Note
This operation disregards any specified image regions. It processes the entire image.
Parameters
imageAn image containing a single calibration plate.
Exceptions
NotPossibleExceptionIf no image is provided.
NotSupportedExceptionIf the image format is not supported.
MismatchExceptionIf the sizes of the image is different to the one given in the intrinsic parameters.
TargetNotFoundExceptionIf the images does not contain any calibration plate.
Since
ids_peak_icv 1.1
