Detailed Description

Represents a three-channel image encoding cartesian coordinates (x, y, z) of a 3D point.

This image is derived from an undistorted depth map that contains embedded intrinsic parameters and uses radial coordinates.

In contrast to radial coordinates, which measure the direct distance from the optical center to the object, cartesian coordinates project these measurements onto a uniform plane.

For example: If the camera faces a flat wall, only the cartesian coordinates will form a flat plane, whereas radial values will increase towards the image edges.
