Detailed Description

Color matrix transformation is an image pipeline module that applies a ColorCorrectionMatrix to an image.

Provides the features features::ColorCorrectionFeature, features::SaturationFeature and features::ChromaticAdaptionFeature

Default configuration:

  • Color correction matrix = 3x3 identity matrix
  • Saturation = 1.0

ids_peak_icv 1.0
