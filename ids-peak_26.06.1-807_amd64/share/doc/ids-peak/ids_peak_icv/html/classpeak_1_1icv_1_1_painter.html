Detailed Description

Provides functionality for painting drawable objects on images.

The Painter enables rendering of objects derived from IDrawable onto images. Supported image formats are RGB8, BGR8, RGBa8, and BGRa8.

You can configure drawing properties such as color and opacity using SetColor() and SetOpacity(). If not explicitly configured, default values from detail::DrawingOptions are applied.

peak::icv::Painter painter{ image };
painter.SetColor(peak::icv::Color(peak::icv::ColorConstant::Blue));
painter.SetOpacity(peak::icv::Opacity(50));
painter.Draw(region);
