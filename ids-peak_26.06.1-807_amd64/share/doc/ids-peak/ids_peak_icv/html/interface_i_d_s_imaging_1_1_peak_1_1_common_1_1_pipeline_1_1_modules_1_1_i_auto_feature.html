Detailed Description

Interface for modules that provide auto-feature functionality.

Defines the members that any auto-feature module must implement.

Auto-feature modules participate in the pipeline and may control other modules (such as gain modules) in order to automatically adjust processing parameters based on runtime data.

Since
IDSImaging.Peak.Common 1.3

◆ SetColorCorrectionMatrix()

void SetColorCorrectionMatrix ( float[] matrix)

Notifies the auto-feature module of the currently used color correction matrix.

Allows the auto-feature module to adjust its internal algorithms and gain values based on the provided color correction matrix.

The matrix represents a 3x3 color correction matrix and is expected to be supplied in row-major order.

Parameters
matrixA read-only span containing exactly nine elements representing a 3x3 color correction matrix.

◆ SetGainModule()

void SetGainModule ( IGain? gainModule)

Called by the pipeline to set the gain module for the auto-feature module.

This method provides the gain module that the auto-feature module may use to apply gain adjustments as needed.

Implementations should not assume ownership of the provided gain module and should not dispose of it.

Parameters
gainModuleThe gain module to be controlled by the auto-feature module.
