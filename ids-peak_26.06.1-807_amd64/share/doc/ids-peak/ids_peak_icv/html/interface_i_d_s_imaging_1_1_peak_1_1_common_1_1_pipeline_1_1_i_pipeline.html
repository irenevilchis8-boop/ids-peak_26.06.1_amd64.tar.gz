Detailed Description

Interface defining the structure and behavior of a processing pipeline.

A pipeline is composed of multiple modules chained together in a defined order. When an input is processed, each module's Process method is called sequentially, and the final result is returned.

Since
IDSImaging.Peak.Common 1.3
