Detailed Description

Strongly typed container for image acquisition metadata.

This class provides a flexible key-value store for metadata entries. It supports both string-based keys for dynamic runtime usage and strongly typed keys for compile-time safety. Values are stored internally as objects and can be accessed via casting or generic retrieval methods.
