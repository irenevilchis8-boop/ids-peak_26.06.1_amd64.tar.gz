Detailed Description

Mirror provides functionality to flip the image left-right or up-down.

When processing images with a Bayer pattern, the result may have a different pixel format, though the bit depth remains unchanged. Ensure your application can handle potential pixel format changes after mirroring.

Defaults
  • no mirroring
