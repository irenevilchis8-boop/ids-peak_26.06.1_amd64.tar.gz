Detailed Description

Interfaces and implementations for defining and controlling data processing pipelines.

This namespace contains the core interfaces, types, and their implementations for creating and managing pipelines that process input data through a sequence of configurable modules to produce output. It provides foundational building blocks for pipeline configuration, execution, and lifecycle management.

All pipeline-related implementations and interface definitions reside in this namespace.
