Detailed Description

A pipeline module for applying tone curve corrections such as gamma adjustment and digital black offset.

Both, gamma and digital black corrections can be individually enabled or disabled.

Default configuration:

  • gamma = 1.0
  • digital black = 0.0
Since
ids_peak_icv 1.0

◆ gamma() [2/2]

None gamma ( self,
float value )

Sets the gamma correction exponent.

This value determines the degree of inverse gamma correction applied during processing, where output values are computed as pow(input, 1/gamma). Higher gamma values lighten the image, while values closer to zero darken it.

Note
The gamma exponent must be within the valid range returned by gamma_range property.
Parameters
valueThe gamma exponent.
Since
ids_peak_icv 1.0
