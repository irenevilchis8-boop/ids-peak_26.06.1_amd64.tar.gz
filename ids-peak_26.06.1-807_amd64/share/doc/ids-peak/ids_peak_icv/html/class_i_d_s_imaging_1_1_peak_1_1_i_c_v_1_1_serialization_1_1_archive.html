Detailed Description

A key-value store that implements the IArchive interface.

The Archive class provides a concrete implementation of a serialization archive that stores data as key-value pairs. It supports various data types including primitives (bool, long, double), strings, nested archives, and arrays of these types.

var archive = new Archive();
archive.SetInt64("A", 1);
archive.SetString("B", "Text");
archive.SetInt64Array("C", new long[] { 1, 2, 3 });
var subArchive = new Archive();
subArchive.SetDouble("a", 1.2);
subArchive.SetBool("b", true);
archive.SetArchive("D", subArchive);
