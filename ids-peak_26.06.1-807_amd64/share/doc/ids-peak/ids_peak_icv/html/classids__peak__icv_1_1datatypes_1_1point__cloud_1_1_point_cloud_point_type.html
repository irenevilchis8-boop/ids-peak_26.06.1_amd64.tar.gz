Detailed Description

Enumeration representing different types of point cloud points.

Attributes: XYZ: Represents a point with X, Y and Z coordinates. XYZ_I8: Represents a point with X, Y, Z coordinates and 8-bit intensity. XYZ_I10: Represents a point with X, Y, Z coordinates and 10-bit intensity. XYZ_I12: Represents a point with X, Y, Z coordinates and 12-bit intensity. XYZ_RGB8: Represents a point with X, Y, Z coordinates and 8-bit rgb.
