Detailed Description

template<typename Type, std::size_t rows, std::size_t columns>
class peak::icv::Array2D< Type, rows, columns >

A class template for a two-dimensional array.

This class allows for the storage and manipulation of a 2D array of a specified type, number of rows, and columns.

Template Parameters
TypeThe type of the elements stored in the array.
rowsThe number of rows in the array.
columnsThe number of columns in the array.
