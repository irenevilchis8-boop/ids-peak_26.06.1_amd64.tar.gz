IArchive Read (Stream stream)
 Reads serialized data from the specified stream and deserializes it into an archive.
 

Detailed Description

Deserializer for reading serialized data and converting it into an IArchive object.

This class provides functionality to read data from a supported serialization format (currently, only JSON) and reconstruct it as an IArchive object. It inherits from peak.common.serialization.IDeserializer and implements the deserialization operations.

using var file = new FileStream("archive.json", FileMode.Open);
var deserializer = new peak::icv.Deserializer();
var archive = deserializer.Read(file);
var id = archive.GetInt64("id");
var name = archive.GetString("name");
