Detailed Description

HotpixelCorrection detects and corrects hot pixels in camera images.

The HotpixelCorrection class is responsible for identifying and correcting defective pixels that consistently report higher-than-expected intensity values.

It allows fine-tuning of the detection sensitivity and management of a hot pixel correction list, which is applied during image processing through the Process() method.

void Detect ( const peak::icv::Image & image,
uint32_t sensitivity = 3,
float gainFactor = 1.0F )
inline

Performs immediate hot pixel detection on the given image.

This method analyzes the provided image and detects hot pixels based on the sensitivity setting. The results are stored internally and can be accessed using GetList().

Parameters
imageThe input image to analyze for hot pixel detection.
sensitivitySensitivity for hot pixel detection. A higher sensitivity may result in detecting more hot pixels, including possible false positives.
gainFactorGain factor applied to the image. Used to account for increased noise levels when detecting hot pixels.
Note
Calling this function will overwrite any existing hot pixel list previously set via SetList().
