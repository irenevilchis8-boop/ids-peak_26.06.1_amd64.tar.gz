Detailed Description

Serializer for writing IArchive objects to an output stream.

This class converts an IArchive object into a specific serialization format and writes the result to a stream.

var archive = new Archive();
archive.SetInt64("id", 42);
archive.SetString("name", "example");
using var file = new FileStream("archive.json", FileMode.Create);
var serializer = new Serializer(SerializationType.Json);
serializer.Write(archive, file);
