Detailed Description

Selects regions based on feature criteria.

Represents a region selector used to filter a specified set of regions based on features such as area or center of gravity. Used to select the regions the user is interested in.

Since
ids_peak_icv 1.1

◆ SelectByCenterOfGravityRect()

RegionSelector SelectByCenterOfGravityRect ( const peak::common::RectangleF & rect)
inline

Selects regions by center of gravity within a rectangle.

Provides regions where: rect.x <= x(region) <= rect.x + rect.width && rect.y <= y(region) <= rect.y + rect.height.

Note
If rect.width and rect.height are zero, the selection is based solely on the point (rect.x, rect.y).
Parameters
rectRectangular interval to select by.
Returns
