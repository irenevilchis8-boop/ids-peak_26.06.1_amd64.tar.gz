Detailed Description

Image pipeline module for applying gain to the image.

A gain module consists of a master gain applied to all channels, along with individual gain values for the red, green, and blue channels.

Since
IDSImaging.Peak.ICV 1.3

◆ Process() [1/2]

override Image Process ( Image input)
inline

Applies the gains to the input image in place and returns a reference to the modified image.

The correction is performed based on the current configuration of the module. The operation modifies the input image directly and does not create a copy.

Note
Supported pixel formats: BayerRG8, BayerRG10, BayerRG12, BayerGR8, BayerGR10, BayerGR12, BayerBG8, BayerBG10, BayerBG12, BayerGB8, BayerGB10, BayerGB12, Mono8, Mono10, Mono12, Mono16.
Note
This operation disregards any specified image regions and processes the entire image.
Parameters
inputThe input image to be processed and corrected.
Returns
A reference to the input image after in-place gain correction.
Exceptions
IcvNotSupportedExceptionThrown when input has any other than the supported pixel formats.
