Detailed Description

Gamma applies an inverse gamma transformation to an image.

This module adjusts the image luminance by applying an inverse gamma correction. This prepares the image for a linear domain or further processing.

The correction is applied independently to each channel in the image. For RGB images, it is applied to each color channel (R, G, B), and for monochrome images, it is applied to the single intensity channel.

The correction is performed using the following formula:

color_value_out = pow(color_value_in, 1.0 / gamma);

where:

  • color_value_in is the input channel value,
  • gamma is the gamma exponent,
  • color_value_out is the resulting output value.
Warning
Gamma values close to zero may result in very dark images, while very high values may cause loss of detail in dark areas. Use values within the range returned by GetRange().

Defaults
  • gamma = 1.0

void SetValue ( float gamma)
inline

Sets the gamma correction exponent.

This value determines the degree of inverse gamma correction applied during processing, where output values are computed as pow(input, 1/gamma). Higher gamma values lighten the image, while values closer to zero darken it.

Parameters
gammaA floating-point value representing the gamma exponent. Valid values are within the range returned by GetRange.
Exceptions
OutOfRangeExceptionIf gamma is outside the valid range.
