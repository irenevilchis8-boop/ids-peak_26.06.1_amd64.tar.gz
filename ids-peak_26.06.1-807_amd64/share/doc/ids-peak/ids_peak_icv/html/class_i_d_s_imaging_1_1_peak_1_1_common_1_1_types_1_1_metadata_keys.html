Detailed Description

Provides a centralized registry of predefined MetadataKey instances.

This static class acts as a catalog for metadata keys used throughout the library. Each key is uniquely identified by its name and associated with a specific value type. Using these predefined keys ensures consistency across different components of the peak ecosystem.

Since
IDSImaging.Peak.Common 1.3

◆ DeviceFrameID

readonly MetadataKeyT<ulong> DeviceFrameID = new("DeviceFrameID")
static

A sequentially incremented identifier for the frame.

The frame ID is a sequentially incremented value that increases by one from one frame to the next. It serves as a means to detect missing or out-of-order frames in a stream. Once the maximum value supported by the underlying technology is reached, the frame ID wraps back to zero. The exact wrap-around point is not fixed and depends on the implementation.

◆ DeviceTimestamp

readonly MetadataKeyT<ulong> DeviceTimestamp = new("DeviceTimestamp")
static

Device-provided image acquisition timestamp in nanoseconds.

The timestamp is expressed in nanoseconds and is relative to an unspecified reference point (t = 0). It does not represent an absolute wall-clock time, but instead the elapsed time since that reference. The difference between timestamps of consecutive images indicates the time interval between their recordings.

Since
IDSImaging.Peak.Common 1.3

◆ SystemTimestamp

readonly MetadataKeyT<ulong> SystemTimestamp = new("SystemTimestamp")
static

Timestamp of the system since unix epoch in nanoseconds.

Provides the system timestamp corresponding to the device timestamp, expressed as nanoseconds since the Unix epoch (00:00:00 UTC on January 1, 1970). This allows data to be associated with a system time, for example for logging or correlating with other system events.

The system timestamp is not intended for high-precision timing due to device-side timestamping and host processing delays. For applications requiring high timing accuracy, use the DeviceTimestamp directly.

Since
