Detailed Description

Color correction matrix.

A color correction matrix is a 3x3 transformation matrix used to adjust RGB color values. It is typically used to convert colors from a camera sensors native RGB space to a standard color space, or to perform color balancing and correction.

The color correction matrix is represented as a 3x3 float array:

┌ ┐
│ m_00 │ m_01 │ m_02 │
│ m_10 │ m_11 │ m_12 │
│ m_20 │ m_21 │ m_22 │
└ ┘
See also
Features.ColorCorrectionFeature

for more information.
