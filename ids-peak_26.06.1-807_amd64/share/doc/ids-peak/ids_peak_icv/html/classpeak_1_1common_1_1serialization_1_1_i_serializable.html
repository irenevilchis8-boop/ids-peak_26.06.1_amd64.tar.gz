Detailed Description

Interface for objects that can be serialized to and deserialized from an archive.

Classes implementing this interface provide mechanisms to convert their internal state into a portable form using an peak::common::serialization::IArchive, and restore it later from the same archive.

Serializes the current object into the provided archive.

This method writes the internal state of the object into the given peak::common::serialization::IArchive so that it can later be reconstructed using Deserialize().
