Detailed Description

Provides convenience extension methods for setting and retrieving values from an IArchive using common CLR types.

These methods are intended as syntactic sugar over the strongly-typed IArchive API. They do not replace the explicit Set/Get methods and should primarily be used at call sites where reduced verbosity is desired.

Supported CLR types are intentionally limited to ensure predictable, cross-language behavior compatible with the C++ archive representation.

Type mapping rules:

  • bool → Bool
  • int / long → Int64
  • float / double → Double
  • string → String
  • IArchive → Archive

Unsupported CLR types are not handled by these helpers unless explicitly documented.

All archive contract rules still apply: missing keys, type mismatches, or unsupported conversions will result in exceptions.

Exceptions
CommonInvalidParameterExceptionThrown if archive or value is null.

The runtime type of value determines which IArchive setter is invoked. If a value already exists under the specified key, it is overwritten.

This method performs widening numeric conversions only (e.g. int → long, float → double).
