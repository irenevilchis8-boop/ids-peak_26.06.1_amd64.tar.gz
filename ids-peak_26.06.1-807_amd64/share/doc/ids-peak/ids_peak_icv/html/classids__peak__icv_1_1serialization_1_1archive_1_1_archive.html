Detailed Description

A key-value store with type checking, based on a dict.

Supports only:

  • bool, int, float, str
  • IArchive
  • Lists of the above (with homogeneous element types)

Example 

from ids_peak_icv.serialization import Archive

archive = Archive()

archive.set("A", 1)
archive.set("B", "Text")
archive.set("C", [1, 2, 3])

sub_archive = Archive()
sub_archive.set("a", 1.2)
sub_archive.set("b", True)
archive.set("D", sub_archive)
