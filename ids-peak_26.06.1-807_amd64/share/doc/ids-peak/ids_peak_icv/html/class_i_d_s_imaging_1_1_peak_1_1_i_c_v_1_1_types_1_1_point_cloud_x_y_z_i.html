Detailed Description

Represents a point cloud consisting of points with x, y, z coordinates and an intensity value.

◆ PointCloudXYZI() [2/4]

PointCloudXYZI ( UndistortedImage undistortedDepthMap,
Image intensityImage )
inline

Constructs a point cloud from the specified undistorted depth map and intensity image.

The intrinsic parameters must be embedded in the image. The depth values must represent distances measured in a spherical coordinate system centered at the camera origin. Each pixel must encode the radial distance to a 3D point. Use the Undistortion class to convert a distorted depth map into an UndistortedImage. The region of the intensity image is disregarded.

Parameters
undistortedDepthMapImage containing distance values per pixel, along with intrinsic camera parameters.
intensityImageImage containing intensity values per pixel.
Exceptions
IcvNotSupportedExceptionThe image format is not supported.
IcvMismatchExceptionThe specified xyzImage and intensityImage do not have the same dimensions.
