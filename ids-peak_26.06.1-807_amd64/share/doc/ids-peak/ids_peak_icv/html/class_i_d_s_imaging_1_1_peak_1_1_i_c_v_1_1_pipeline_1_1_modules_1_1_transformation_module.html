Detailed Description

Transformation is an image pipeline module that provides mirror and rotation functionality.

See also
Features.MirrorFeature, Features.RotationFeature
Since
IDSImaging.Peak.ICV 1.3

◆ Process() [1/2]

override Image Process ( Image inputImage)
inline

Processes the input image and returns a mirrored and/or rotated copy based on current settings.

Note
Supported pixel formats: BayerGR8, BayerGR10, BayerGR12, BayerRG8, BayerRG10, BayerRG12, BayerGB8, BayerGB10, BayerGB12, BayerBG8, BayerBG10, BayerBG12, Mono8, Mono10, Mono12, Mono16, Confidence8, Confidence16, Coord3D_C8, Coord3D_C16, Coord3D_C32f, Coord3D_ABC32f, RGB8, RGB10, RGB12, BGR8, BGR10, BGR12, RGBa8, RGBa10, RGBa12, BGRa8, BGRa10, BGRa12, Mono32f, RGB32f
Note
When processing images with a Bayer pattern, the result may have a different pixel format, though the bit depth remains unchanged.
Note
This operation disregards any specified image regions and processes the entire image.
Parameters
inputImageThe input image to be processed.
Returns
A new image object that is the transformed result of the input.
Exceptions
IcvNotSupportedExceptionThe inputImage has any other than the supported pixel formats.

◆ ResetToDefault()

override void ResetToDefault ( )
inlinevirtual

Resets all parameters to their default values.

Default values:

  • MirrorLeftRight = false
  • MirrorUpDown = false
  • RotationAngle = Rotation.None
Note
The enabled state does not change when calling this function.
