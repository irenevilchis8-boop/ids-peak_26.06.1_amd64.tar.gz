Detailed Description

Hotpixel correction is an image pipeline module for detecting and correcting hot pixels in camera images.

Provides the feature HotpixelCorrectionFeature.

◆ detect()

None detect ( self,
Image image,
int sensitivity = 3,
float gain_factor = 1.0 )

Performs immediate hot pixel detection on the given image.

This method analyzes the provided image and detects hot pixels based on the sensitivity setting. The results are stored internally and can be accessed using pixel_list.

Note: Calling this function will overwrite any existing hot pixel list previously set via pixel_list.

Parameters
imageThe input image to analyze for hot pixel detection.
sensitivitySensitivity for hot pixel detection. A higher sensitivity may result in detecting more hot pixels, including possible false positives.
gain_factorGain factor applied to the image. Used to account for increased noise levels when detecting hot pixels.
Exceptions
NotSupportedExceptionIf image has any other than the supported pixel formats.
Since
ids_peak_icv 1.0

Applies hot pixel correction to the input image in place and returns a reference to the modified image.

Supported pixel formats

  • Mono10
  • Mono12
  • BayerBG8
  • BayerBG10
  • BayerBG12
  • BayerGB8
  • BayerGB10

  • BayerRG12
  • BayerGR8
  • BayerGR10
  • BayerGR12

See the Pixel and Pixel Format Specifications for a detailed description of the pixel formats.

The correction is performed based on the current configuration of the module. The operation modifies the input image directly and does not create a copy.

This operation disregards any specified image regions and processes the entire image.
