Detailed Description

Color matrix transformation is an image pipeline module that applies a Types.ColorCorrectionMatrix to an image.

Provides the features ColorCorrectionFeature, SaturationFeature and ChromaticAdaptionFeature

Default values:

  • Matrix = Types.ColorCorrectionMatrix.Identity
  • Saturation = 1.0f
  • ChromaticAdaptionAlgorithm = Types.ChromaticAdaptionAlgorithm.Bradford
  • ColorSpace = ColorSpace.SRGB_D65
  • ColorTemperature = null (chromatic adaption won't be applied)
Since
IDSImaging.Peak.ICV 1.3
