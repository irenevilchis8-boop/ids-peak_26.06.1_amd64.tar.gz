IArchive CreateArchive ()
 Creates a new, empty archive instance of the same concrete type.The returned archive is empty and not automatically stored in the current archive.
 

Detailed Description

Base class for IArchive implementations.

This class does not currently provide shared behavior. It exists to allow future extension and to provide a common inheritance root.

Since
IDSImaging.Peak.Common 1.3
