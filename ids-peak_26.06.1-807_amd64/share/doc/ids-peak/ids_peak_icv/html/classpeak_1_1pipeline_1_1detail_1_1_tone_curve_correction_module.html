Detailed Description

Tone curve correction is an image pipeline module that applies digital black correction and inverse gamma transformation to an image.

See also
features::DigitalBlackFeature and features::GammaFeature
Since
ids_peak_icv 1.0

◆ SetGamma()

void SetGamma ( float gamma)
inline

Sets the gamma correction exponent.

This value determines the degree of inverse gamma correction applied during processing, where output values are computed as pow(input, 1/gamma). Higher gamma values lighten the image, while values closer to zero darken it.

Note
The gamma exponent must be within the valid range returned by GetGammaRange().
Parameters
gammaThe gamma exponent.
