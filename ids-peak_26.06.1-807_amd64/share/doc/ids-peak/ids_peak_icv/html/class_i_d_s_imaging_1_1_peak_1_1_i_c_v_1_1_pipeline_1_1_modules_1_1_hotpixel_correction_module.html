Detailed Description

Hotpixel correction is an image pipeline module for detecting and correcting hot pixels in camera images.

◆ Detect()

void Detect ( Image image,
uint sensitivity = 3,
float gainFactor = 1::0F )
inline

Performs immediate hot pixel detection on the given image.

This method analyzes the provided image and detects hot pixels based on the current sensitivity setting. The results are stored internally and can be accessed using GetList().

Note
Supported pixel formats: BayerGR8, BayerGR10, BayerGR12, BayerRG8, BayerRG10, BayerRG12, BayerGB8, BayerGB10, BayerGB12, BayerBG8, BayerBG10, BayerBG12, Mono8, Mono10, Mono12
Warning
Calling this function will overwrite any existing hot pixel list previously set via SetList(). All previously configured hot pixel positions will be lost.
Parameters
imageThe input image to analyze for hot pixel detection.
sensitivitySensitivity for hot pixel detection. A higher sensitivity may result in detecting more hot pixels, including possible false positives. Valid values are within the range returned by SensitivityRange.
gainFactorGain factor applied to the image (typically 1.0 or higher). Used to account for increased noise levels when detecting hot pixels. Higher gain factors may require higher sensitivity values for effective detection.
Exceptions
IcvOutOfRangeExceptionThe sensitivity value is outside the valid range.
IcvNotSupportedExceptionThe image has any other than the supported pixel formats.
See also
HotpixelList, SensitivityRange

◆ Process() [1/2]

override Image Process ( Image inputImage)
inline

Applies hot pixel correction to the input image in place and returns a reference to the modified image.

The correction is performed based on the current configuration of the module. The operation modifies the input image directly and does not create a copy.

Note
Supported pixel formats: BayerGR8, BayerGR10, BayerGR12, BayerRG8, BayerRG10, BayerRG12, BayerGB8, BayerGB10, BayerGB12, BayerBG8, BayerBG10, BayerBG12, Mono8, Mono10, Mono12.
Note
This operation disregards any specified image regions and processes the entire image.
Parameters
inputImageThe input image to be processed and corrected.
Returns
A reference to the input image after in-place hot pixel correction.
Exceptions
IcvNotSupportedExceptionThe inputImage has any other than the supported pixel formats.
