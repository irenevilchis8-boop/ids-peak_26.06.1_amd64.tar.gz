Detailed Description

Digital black applies digital black correction to an image.

Supported pixel formats

See the Pixel and Pixel Format Specifications for a detailed description of the pixel formats.

This feature adjusts the image luminance by first subtracting a digital black and then normalizing the result. This compensates for sensor digital black offsets. The correction is applied independently to each channel in the image. For RGB images, it is applied to each color channel (R, G, B), and for monochrome images, it is applied to the single intensity channel.

The correction is performed using the following formula:: 

color_value_out = clamp((color_value_in - black) / (1.0 - black), 0.0, 1.0);

where:

  • color_value_in is the input channel value
  • black is the digital black to be subtracted (in normalized units)
  • color_value_out is the resulting output value

All input and output values are in the normalized range [0.0, 1.0].

The default value for digital black is 0.0.
