Detailed Description

Class holding a color palette (a set of colors).

This class cycles through a predefined list of colors.

ColorPalette ( ColorPaletteConstant constant,
byte numBitsPerPixel = 8 )
inline

Creates a color palette from a color palette constant.

The colors in the palette are:

  • ColorConstant.Red, ColorConstant.Green, ColorConstant.Blue (for ColorPaletteConstant.Colored3)
  • ColorConstant.Red, ColorConstant.Green, ColorConstant.Blue, ColorConstant.Yellow, ColorConstant.Magenta, ColorConstant.Cyan (for ColorPaletteConstant.Colored6)
Parameters
constantThe color palette constant.
numBitsPerPixelNumber of bits per pixel. Defaults to 8.
Exceptions
IcvNotSupportedExceptionAn invalid palette constant is provided.
