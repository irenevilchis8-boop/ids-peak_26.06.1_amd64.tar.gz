Calculate the byte size of an image buffer for a given size and pixel format.

Parameters
sizeThe image dimensions (width, height) in pixels.
bits_per_pixelThe number of storage bits per pixel for the pixel format.
packed_or_yuvIf True, assumes packed or yuv format (truncate bits to full bytes). If False, assumes other format (round up to nearest byte).
Returns
The byte size of the buffer.
