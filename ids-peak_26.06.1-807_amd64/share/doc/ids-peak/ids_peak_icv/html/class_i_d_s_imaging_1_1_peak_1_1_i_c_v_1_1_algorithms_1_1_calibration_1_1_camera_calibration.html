Detailed Description

Camera calibration representation holding the logic to compute intrinsic and extrinsic parameters.

This class represents the camera calibration process. It requires a CalibrationPlate instance that provides the world coordinates of the reference points on the physical calibration plate. These points are needed to calculate the camera parameters.

The main operation is the CameraCalibration.Process() method, which calculates intrinsic and extrinsic parameters from input images.

CalibrationResult Process ( DisposableList< Image > images)
inline

Calculates intrinsic and extrinsic parameters.

Processes several images showing the calibration plate in different poses to accurately calculate camera calibration parameters.

The calibration process involves detecting the reference points in the images and matching them to their known world coordinates provided by the calibration plate. Using these correspondences, the method estimates the camera’s intrinsic parameters (such as focal length and distortion) and extrinsic parameters (position and orientation).

Note
Processes the entire image, ignoring any specified image region.
Parameters
imagesA list of images of a calibration plate in different poses.
Returns
The calibration results, including intrinsic and extrinsic parameters.
Exceptions
IcvNotSupportedExceptionThe pattern of the calibration plate is not supported or the image has an unsupported format.
IcvMismatchExceptionThe images do not all have the same size.
IcvTargetNotFoundExceptionThe marker points were not found on the given image.
