Detailed Description

Unpack is an image pipeline module that converts packed pixel formats into corresponding unpacked Bayer or mono formats.

The unpack module is always enabled and cannot be disabled. It converts input images with packed pixel formats into their corresponding unpacked Bayer or monochrome formats. The output bit depth depends on the applied processing policy and the specified target bit depth.

Default values:

  • Target bit depth: 8
  • Processing policy: Types.ProcessingPolicy.Fast

◆ ReleaseBuffers()

void ReleaseBuffers ( )
inline

Frees unused internal buffers.

This module uses pre-allocated internal buffers to accelerate conversions. When the image size or pixel format changes, new buffers are allocated, which may cause the internal buffer pool to grow over time. This function can be used to release unused buffers and reduce memory usage.

Note
Avoid calling this function too frequently (e.g., after every resize or format change), as it introduces some overhead.

◆ TargetBitDepth

uint TargetBitDepth = DefaultTargetBitDepth
getset

The target bit depth used during image processing.

This value specifies the bit depth the module will aim for when unpacking packed pixel formats. The actual output bit depth depends on the selected Types.ProcessingPolicy:

  • Fast: The output bit depth is the minimum of the input image bit depth and the target bit depth.
  • Balanced: The output bit depth is the same as the input image bit depth (the target value is ignored).
  • Enhanced: The output bit depth is the maximum of the input image bit depth and the target bit depth.

This allows you to downsample, preserve, or enhance bit depth depending on your use case.
