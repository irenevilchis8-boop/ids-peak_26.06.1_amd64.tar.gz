Detailed Description

Types representing geometric concepts such as points, sizes, rectangles, and vectors.

This subgroup focuses on types commonly used to represent and manipulate geometric data. It includes templates and type aliases for points, rectangles, sizes, and vectors, which are useful in image processing, spatial computations, and graphical applications.

Since
ids_peak_common 1.0
