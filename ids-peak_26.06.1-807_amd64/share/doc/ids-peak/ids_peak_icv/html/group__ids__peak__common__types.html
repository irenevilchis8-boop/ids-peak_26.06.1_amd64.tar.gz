Detailed Description

General-purpose types and interfaces used throughout the library.

This module contains a collection of core types that are widely used across different components of the library. These types among others include utility types such as ranges, intervals, type-erased containers (e.g., Any), pixel formats, image view interfaces, and other foundational constructs.

The types in this group are intended to provide reusable, versatile building blocks for applications and other libraries built on top of this component.

Since
ids_peak_common 1.0

Represents the various data channels in image or spatial data formats.

This enumeration defines semantic labels for the different components that can be found in pixel-based or point cloud data representations.
