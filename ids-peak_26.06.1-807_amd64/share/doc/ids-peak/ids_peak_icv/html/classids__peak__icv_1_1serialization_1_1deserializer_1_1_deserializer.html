Detailed Description

Deserializer for reading serialized data and converting it into an IArchive object.

This class provides functionality to read data from a supported serialization format (currently, only JSON) and reconstruct it as an IArchive object.

Example 

from ids_peak_icv.serialization import Deserializer, SerializationType

deserializer = Deserializer(SerializationType.JSON)
with open("archive.json", "r") as f:
    archive = deserializer.read(f)

id = archive.get("id", int)
name = archive.get("name", str)
