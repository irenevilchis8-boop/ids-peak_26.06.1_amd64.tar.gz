Detailed Description

Object serialization.

Serialization refers to the process of transforming an object’s state or a data structure into a format suitable for storage or transmission (e.g., files, databases, or network streams). This allows data to be persisted and later reconstructed through deserialization, restoring the original structure and values.

Typical use cases include:

  • Saving application state to disk
  • Transferring data between processes or systems

Enumeration of supported serialization formats.

This enumeration defines the data formats available for serializing and deserializing IArchive objects. The serialization system uses this type to select the appropriate format for reading and writing archive data.
