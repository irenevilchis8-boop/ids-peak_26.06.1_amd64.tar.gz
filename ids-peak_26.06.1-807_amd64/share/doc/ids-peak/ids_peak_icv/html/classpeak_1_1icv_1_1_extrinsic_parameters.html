Detailed Description

This class stores and provides access to the extrinsic parameters, which include the translation, rotation, and transformation matrix.

It is a result of the camera calibration or the workspace calibration.

The extrinsic camera parameters describe the transformation between the camera's coordinate system and the world coordinate system. They can be used to convert points from the world coordinate system into the camera coordinate system.
