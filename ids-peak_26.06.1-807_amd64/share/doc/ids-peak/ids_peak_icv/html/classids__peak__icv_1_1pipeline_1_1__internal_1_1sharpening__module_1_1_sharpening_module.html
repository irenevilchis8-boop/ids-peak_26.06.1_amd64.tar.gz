Image process ( self,
Image input_image )

Apply sharpening to the specified image.

Supported pixel formats
  • Mono8
  • Mono10
  • Mono12
  • BGR8
  • BGRa8
  • RGB8
  • RGBa8
  • BGR10
  • BGRa10
  • RGB10
  • RGBa10
  • BGR12
  • BGRa12
  • RGB12
  • RGBa12

See the Pixel and Pixel Format Specifications for a detailed description of the pixel formats.

If sharpening is disabled or the sharpening level is set to 0, the input image is returned unchanged. Otherwise, this method applies an in-place sharpening operation using the configured level.

Parameters
input_imageInput image to be processed.
Returns
Processed output image.
