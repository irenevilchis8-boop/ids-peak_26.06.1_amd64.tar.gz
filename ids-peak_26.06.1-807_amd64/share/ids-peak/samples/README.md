# IDS peak examples

The IDS peak examples are now maintained in our GitHub repository
instead of being fully included in the local SDK installation.

This approach allows us to provide:
- more frequent updates and bug fixes
- improved and extended documentation
- additional example projects
- easy access to the latest versions
- issue tracking and community feedback
- the possibility for users to contribute improvements and new examples

## Access the examples

All available examples can be found here:

https://github.com/ids-imaging/ids-peak-examples

## Structure

Examples are organized into language-specific subfolders, for example:
- `cpp/`
- `csharp/`
- `python/`
